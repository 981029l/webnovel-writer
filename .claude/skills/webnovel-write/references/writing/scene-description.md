## ⚠️ 使用前必读：先锁定题材氛围（最高优先级）

本文件是**多题材通用技法**，但**氛围基调必须由【当前题材】决定**，绝不套用默认。
本文档里所有单一示例（尤其光影、天气、声音的联想）都只是"某个题材下"的可能写法，**不是通用真理**。

写任何场景前，先问自己三个问题：
1. 当前题材是什么？它的核心阅读体验是"爽/燃"、"心动/甜虐"、"烟火气/共鸣"、"典雅/机锋"，还是"压迫/未知"？
2. 这个场景要为哪种情绪服务？
3. 我要用的氛围词，是否属于下方【按题材氛围大表】中**当前题材那一列**？

**铁律**：只有「规则怪谈/黑暗题材」才允许把场景写成阴森、未知、压抑、诡异。
其余所有题材若出现"死寂、窒息、诡异的安静、阴冷、像有什么在注视、莫名的不安"等基调主导场景，即为**跑偏**，必须换成当前题材的正确氛围词。

## 一、五感层次

### 视觉（最重要）
- 动作：轨迹、速度、力度
- 特效：光芒、色彩、形态
- 环境：变化、破坏、氛围
- 表情：微表情、眼神、姿态

### 听觉
- 声音：对话、呼吸、心跳
- 音效：碰撞、破碎、风声
- 沉默：无声的张力感
- 语调：语气、节奏、情绪

### 触觉
- 温度：热、冷、温、凉
- 力度：轻、重、紧、松
- 质感：滑、糙、软、硬
- 动态：静止、移动、颤动

### 嗅觉
- 体香：标记身份、传递吸引力
- 气息：呼吸、体温携带的气味
- 环境：场景气味、氛围营造
- 变化：从淡到浓暗示情感发展

### 味觉
- 直接：食物、饮品
- 隐喻：苦涩、甜蜜、酸楚
- 情感：用味觉表达情绪

## 二、感官交织方法

### 并列式
多感官同时呈现，增强丰富度
```
他的手指划过她的脸颊【触觉】，
带着淡淡的烟草味【嗅觉】，
她听到自己心跳加速的声音【听觉】。
```

### 递进式
感官强度逐步升级，推动情感高潮
```
先是若有若无的香气【嗅觉·弱】，
然后是指尖的轻触【触觉·中】，
最后是灼热的呼吸喷在耳边【触觉+听觉·强】。
```

### 对比式
不同感官形成对比，增强层次感
```
外面是刺骨的寒风【触觉·冷】，
他的怀抱却温暖如春【触觉·暖】。
```

## 三、场景类型感官重点

| 场景类型 | 主感官 | 重点 |
|----------|--------|------|
| 战斗场景 | 视觉+听觉+触觉 | 动作轨迹、碰撞声、冲击感 |
| 情感场景 | 触觉+嗅觉+听觉 | 肌肤接触、体香、呼吸心跳 |
| 环境场景 | 视觉+听觉+嗅觉 | 景色光影、环境音、场景气味 |
| 美食场景 | 味觉+嗅觉+视觉 | 口感味道、香气热气、色泽摆盘 |
| 紧张场景 | 听觉+触觉+视觉 | 急促脚步、心跳加速、昏暗光线 |

## 四、感官描写技巧

### 具体化
```
❌ 她很香。
✅ 她身上有淡淡的栀子花香，混着阳光晒过的温暖气息。
```

### 动态化
```
❌ 他的手很温暖。
✅ 他的指尖划过她的手背，留下一道温热的痕迹。
```

### 情感化
```
❌ 风很冷。
✅ 寒风像刀子一样割在脸上，和她离去时的眼神一样冰冷。
```

### 对比化
```
她的嘴唇是冰凉的，但吻却灼热得让人窒息。
```

## 六、环境氛围营造（按题材分列 — 严禁套用单一默认）

⚠️ **同一个自然元素（阴影、雾、寂静、月光、雨），在不同题材里指向完全不同的情绪。**
下表每一格都是"该题材下的正确联想"。写作时**只查当前题材那一列**，不要用"神秘/未知"这种诡异向默认值污染非怪谈题材。

| 元素 | 玄幻 | 现代言情 | 都市现实 | 古言 | 规则怪谈/黑暗 |
|------|------|---------|---------|------|-------------|
| **寂静** | 全场震慑的死寂（震惊反应）、闭关时的空明 | 两人独处时的安静、心跳被放大 | 深夜加班的空office、散场后的街道 | 大殿之上的肃穆、深宫的规矩森严 | 不对劲的死寂、被抽走声音的空间 ✅ |
| **阴影/暗** | 强敌威压、势力暗涌、灵光下的对比 | 睫毛在脸上投下的阴影（心动特写）、路灯下拉长的两人影子 | 高楼间的压迫感、加班楼里唯一亮着的窗 | 屏风后的暗流、帘幕后的窥探 | 藏着东西的黑、不敢看的角落 ✅ |
| **雾/朦胧** | 秘境灵雾、机缘征兆、云海翻涌 | 清晨朦胧的温柔、呵出的白气模糊了视线 | 城市晨雾、通勤路上的疲惫感 | 烟雨江南的雅致、水墨般的远山 | 遮蔽视线、吞掉退路的未知 ✅ |
| **月光** | 清辉映剑、夜战、月下修行 | 浪漫暧昧、月色下的告白 | 加班归途的清冷、出租屋窗前的孤独 | 庭院幽会、月下独酌的心事 | 惨白失真、照出不该有的影子 ✅ |
| **雨** | 洗练、蓄势、雨中悟道 | 心疼、被动接近（避雨、送伞）| 生活的疲惫、湿透的通勤 | 离愁别绪、雨打芭蕉的孤寂 | 阴冷压抑、雨声盖住脚步声 ✅ |
| **风** | 剑气、气势、山风呼啸 | 撩起发丝的暧昧、带来他的气息 | 穿堂风、空调风的办公室感 | 卷起帘幕、吹动烛火的暗示 | 无风自动、莫名的凉意 ✅ |

**读表方式**：找到当前题材那一列，用该列的意象和情绪来组织描写。
带 ✅ 的「规则怪谈/黑暗」列是**唯一**允许诡异、未知、压抑基调的地方，其余题材严禁调用该列词汇。

### 声音运用（同理分列）
```
喧嚣 → 各题材通用：混乱、热闹、市井烟火
自然声 → 玄幻(灵禽/泉鸣)、言情(治愈)、都市(白噪音)、古言(丝竹/更漏)
机械声 → 都市现实专属：现代感、冷漠、程式化
```

| 场景类型 | 字数建议 | 示例关键词 |
|----------|----------|------------|

| 战斗场景 | 几乎不描写 | 除非环境影响战斗 |

## 八、动静结合

### 静态描写（枯燥）
```
山峰很高，树很绿，天很蓝。
```

### 动态描写（生动）
```
山峰直插云霄，山风呼啸而过，卷起漫天落叶。树林深处传来兽吼，几只灵鸟惊飞而起，翅膀扇动间，羽毛飘落如雪。
```

**技巧**: 加入动词（呼啸、卷起、传来、飞起、扇动、飘落）

## 九、人物与场景互动

### 错误示例（分离）
```
【场景】房间很暗，只有一根蜡烛。
【人物】林天走了进来。
```

### 正确示例（融合）
```
林天推开门，房间内昏暗一片，唯有桌上一根蜡烛摇曳着微弱的光。
他眯起眼睛，借着烛光扫视四周——破旧的桌椅、落满灰尘的书架、角落里的蜘蛛网……
"好久没人住了。"他皱眉。
```

<errors>
❌ 过度描写（流水账列举所有细节） → ✅ 只写核心特征，其余让读者脑补
❌ 堆砌感官（五感全用且篇幅相当） → ✅ 突出1-2个主感官，其他点缀
❌ 感官错位（"看到"香气，除非通感修辞） → ✅ 感官使用准确
❌ 过度渲染（连续三段描写同一感官） → ✅ 感官变化，避免读者疲劳
❌ 脱离情节（大段感官描写与情节无关） → ✅ 感官描写服务于情节氛围
❌ 场景与人物分离 → ✅ 人物与场景互动融合
❌ 静态堆砌（"很大、很高、很美"） → ✅ 动词让场景活起来
</errors>
