# 星际文明流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

"远望号"跃出虫洞的第七秒，探测阵列先于任何人发现了那个信号。

"舰长，赤砂星系第四行星轨道上有规律性电磁脉冲，周期十一秒，人工源。"通讯官的声音绷得很直，"这片星域的档案标注是——无主荒域。"

程野放下手里的航行日志。无主荒域里出现人工信号，只有两种可能：有人比联合殖民署的档案跑得更快，或者，档案本身就在撒谎。

"远望号"是他的全部家当：一艘改装过的中型勘探舰，聚变引擎，二十七名船员，外加一纸随时可能作废的荒域勘探许可。按合同，他们此行的目标是替后方的殖民财团标定三颗宜居候选星，报酬够全船吃两年。但程野盯着那个十一秒一跳的脉冲，改了主意。

"航向修正，去第四行星。"他说，"标定宜居星的钱是死的。荒域里一个没登记的人工信号，可能是活的。"

大副皱眉："财团的合同期限……"

"合同要求我们勘探这片星域。"程野调出星图，把第四行星圈了出来，"我现在就在勘探。"

三天亚光速航程后，第四行星的轨道上，一座半埋在陨石带里的环形结构显出了轮廓——那不是任何已知文明的造物。

## 核心场面

麻烦追着他们的跃迁尾流来了：三艘武装舰，涂着"垦拓集团"的鹰徽，光秒外一字排开。

"远望号，你舰闯入本集团先占勘探区。十分钟内退出轨道，否则视为敌对。"

程野看着战术屏。对方两艘护卫舰一艘驱逐舰，火力是远望号的六倍——正面交火没有任何悬念。但先占勘探区是要向殖民署备案的，对方没有备案，否则档案不会写"无主荒域"。垦拓集团在偷偷挖这处遗迹，见不得光，这就是他的牌。

"回复他们：我舰已在四小时前通过跃迁中继向殖民署提交了遗迹发现报告，附坐标。"程野顿了顿，"再补一句——按《荒域公约》第九条，发现者享有优先勘探权，武装驱逐发现者，殖民署仲裁舰队会在四十个标准日内抵达。"

频道沉默了两分钟。

"他们的驱逐舰在给主炮充能！"雷达官喊道。

"意料之中，吓唬人。"程野的手指却已经按在跃迁预案上，"全舰注意，他们真正的选择只有一个——谈。挖了一半的遗迹，四十天搬不完；打沉我们，仲裁舰队来了他们什么都留不下。"

第七分钟，对方旗舰的通讯灯亮了。垦拓集团的现场主管出现在屏幕上，脸色像吞了铁渣："程舰长。谈谈？"

"谈谈。"程野靠回舰长席，"从遗迹收益的三成开始谈。"

## 收益兑现

最终的协议签在双方数据链上：远望号让渡"优先发现权"备案顺位，换遗迹开采收益的二成五、外加垦拓集团已破译的遗迹外围数据全本。

数据传输完成的那个夜班，全舰的科学组没一个人睡觉。

"舰长,你得看看这个。"首席科学家白岚把分析结果推上主屏,声音发飘,"遗迹外壁的合金,耐受温度是我们最好的舰体材料的四倍。还有这个——"她放大一段结构图,"环形体内部有能量回路残留,拓扑结构和我们的聚变约束场同源,但效率推算值……高出两个数量级。"

两个数量级。程野盯着那段回路图,慢慢坐直了。联邦最顶尖的实验室还在为约束场效率提升百分之十开庆功会,而答案就冻在这片"无主荒域"的陨石带里。

账面收益已经够惊人:二成五的开采分成,按垦拓集团的评估,是远望号那份殖民合同报酬的四十倍;合金样本三吨,已入货舱。但真正的收获是航海图上那三个新标记——白岚从遗迹数据里还原出的坐标,同一个失落文明,至少还有三处遗存,散布在临近的两个星系。

垦拓集团不知道这三个坐标。殖民署也不知道。

"下一站?"大副问。

程野把星图上最近的那个标记点亮,淡金色的光点在漆黑的星域里像一粒火种。"先回港,把船换了。"他说,"这张牌桌,勘探舰坐不住了。"

大副还想问什么,程野已经调出了三个坐标的连线。三点勾出的方向,指向星图边缘一片连联合殖民署都标着问号的深空。他盯着那片空白看了很久——上一卷他以为自己在勘探一个星系,现在才看清,那不过是棋盘的一角。
