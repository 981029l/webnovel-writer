# 机甲战争流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

出击铃响的时候，林逐正给"灰隼"的左肩关节上最后一道锁扣。

"灰隼"是台老掉牙的三代量产机，出力只有主流机型的七成，装甲薄得像纸。但这三个月他亲手把它拆了两遍：卸掉背部的冗余挂架减重四百公斤，机动性提了一档；散热管路重新走线，过热警戒线从连续作战九十秒延到一百四十秒。参数表上它还是垃圾，跑起来已经不是了。

"E-7小队，敌袭！矿区外围发现掠夺者机甲，四台，正在拆采矿平台！"通讯频道里，队长的声音又急又哑，"能动的全部升空！"

林逐翻进驾驶舱，合舱、通电、同调链接，一气呵成。视野展开的瞬间，AI副官"知更"的合成音响起："同调率百分之八十九，今日最佳。燃料满载，实弹七成。"

"够了。"弹射轨道的蓝光在前方铺开，林逐推下节流阀，"灰隼，出击。"

机体被弹射力压进座椅的瞬间，他已经在算了：四台掠夺者机，两台在拆平台，两台警戒。警戒机的站位有个十五度的射界重叠盲区——从矿渣山背面切进去，能打一个措手不及。矿区的地形他闭着眼都能画出来，这半年守着这片外围，值了。

## 核心场面

第一发穿甲弹从矿渣山棱线上掠出，正中警戒机的推进器组。

那台掠夺者机侧旋着栽下去，还没落地，林逐已经借着下滑的惯性冲进两机之间的盲区。第二台警戒机慌忙转身，肩炮的射界却被自家僚机的残骸挡了半拍——就这半拍，"灰隼"贴了上去，高频振动刃从它腋下装甲的接缝里整根送入，绞碎驱动核心。

"两台拆平台的放弃作业，正在合围。"知更报数，"左侧机型识别：五代改装机'裂颚'，出力是本机的一点八倍。"

一点八倍。硬拼是找死。

裂颚的重斩劈下来，林逐没有格挡，反向催动推进器擦着刃锋滑进对方内圈——出力差在贴身战会被抵消一半，这是他拆了两遍灰隼换来的认知。振动刃连点三下，全部被弹开，裂颚的膝部推进器一喷，反而把灰隼撞得倒飞出去，左臂装甲整块剥落。

"左臂驱动效率降至百分之六十。散热剩四十秒。"

林逐盯着弹道预测线，忽然把机体砸向采矿平台的传送带轨道。裂颚追进来的瞬间，他一炮打断头顶的矿斗吊索——三十吨矿石当头砸落，裂颚抬臂格挡的刹那，上半身射界全空。

灰隼从矿石瀑布的侧面钻出，振动刃直入驾驶舱下方的动力舱。

轰。裂颚的核心殉爆，火光把矿区照成了白昼。最后一台掠夺者机调头就跑，林逐没追——燃料余量百分之二十二，见好就收。

## 收益兑现

返航后的结算单，比林逐预想的还厚。

击坠三台，其中一台五代改装机，战功核算下来是他从军以来最大的一笔：军功点四百六十，直接从下士跳到上士；矿业公会另发了一笔护矿酬金，八万联邦币。但真正让机库炸锅的是缴获——裂颚的残骸判归E-7小队，那台机的聚变炉芯只烧毁了外壳，炉体完好。

"五代炉芯，出力比灰隼现在这颗高百分之六十。"技师长围着残骸转了三圈，看林逐的眼神像看疯子，"你拿三代机的机体硬吃五代炉的出力，管路全得重做。"

"重做。"林逐说，"管路我自己画，三个月前就画好了。"

半个月后，换芯完毕的灰隼在试车台上启动。出力表的指针一路爬过旧极限，稳稳停在从前的一点五倍；散热、机动全部重新标定。管路重做那几天，技师长带着两个徒弟给他打下手，边干边摇头，说这套走线图要是拿去军部，够评个技术勋章。知更的合成音里少见地带了点波动："综合性能评估：已达四代主力机上限。命名档案是否更新？"

"不更新。"林逐握着操纵杆，感受着那股沉在机体深处的新力量，"它还叫灰隼。"

战区公告栏上，他的名字第一次进了驾驶员击坠榜，第五十一位。榜首那个王牌的名字后面，跟着一百七十次击坠，机型一栏写着他没见过的代号。

差一百多次。林逐把那个名字记下了。
