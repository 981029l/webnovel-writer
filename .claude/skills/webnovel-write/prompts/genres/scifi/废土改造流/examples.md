# 废土改造流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

废料场西角那台柴油发电机，在别人眼里是一坨锈铁，在江图眼里是活的。

机体锈穿的只是外壳，缸体完好；喷油嘴堵死了，可以拆下来用煤油泡；启动电机烧了，但他上周在坍塌的修理铺里挖到过一台同型号的。真正的问题是缺一条传动皮带——这个可以用轮胎内衬现裁。

"三天。"江图对着发电机自言自语，"三天让你转起来。"

他在这片废墟里落脚两个月了。旧加油站的地下储藏室改的安全屋，铁门加了双闩；屋顶接了四块从光伏板残骸上拆的电池片，只够点一盏灯、充一台对讲机。水靠三公里外的浑河，每天来回挑两趟，明矾沉淀，纱布过滤，煮沸——麻烦，但喝不死人。

发电机是他计划里的第一块基石。有了稳定电力，就能带动他从水厂废墟里拖回来的那台小型水泵，水泵接上他焊了一半的砂滤罐，净水的产量能翻十倍。多出来的水，在这片废土上就是硬通货。

他把发电机的锈壳整个卸下来，零件按顺序摆在帆布上，一样样登记进本子。

天黑前，喷油嘴已经泡进了煤油罐。

## 核心场面

发电机是在第四天下午转起来的，掠夺者是在第六天夜里来的。

七个人，两辆改装摩托，头目拎着一把锯短的霰弹枪，在加油站外围喊话："里面的，听说你这儿有电有净水。识相的交出来，留你全尸。"

江图趴在储藏室的观察口后面，不慌。这两天他没光顾着高兴——发电机一响，方圆两公里都听得见，他早知道会引来什么。所以电线除了接水泵，还接了三样东西。

第一样，是埋在外围碎石带下的两排铁蒺藜，连着警报线。头一辆摩托压上去，前胎当场瘪掉，车手栽进碎石堆。

第二样，是加油站顶棚上那四盏从大巴残骸里拆的远光灯头。江图合上闸，四道强光同时砸向来人的眼睛——在漆黑了十几年的废土上，没人的瞳孔受得了这个。七个人瞬间捂眼乱作一团。

第三样，是他用摩托车电瓶和高压包改的电网，通着安全屋外那圈铁丝网。头目瞎着眼摸到铁门前，一把抓上铁丝网,整个人被电得弹出去半米,霰弹枪脱手落地。

江图这才推开射击孔,用捡来的旧步枪对着人群上方点了两发。

"枪、摩托、油,留下。"他的声音在强光后面,平得像在谈生意,"人可以走。再来,灯就不是照眼睛的了。"

七个人互相搀着,消失在黑暗里。江图断了电闸,清点战利品:霰弹枪一把,弹六发,摩托两辆——一辆胎瘪了,能修。

## 收益兑现

半个月后，江图的据点第一次在夜里亮起了灯。

不是安全屋里那盏，是立在加油站顶棚上的探照灯，天黑后亮两个小时——他故意的。在这片入夜就漆黑的废土上，一盏稳定的灯就是招牌，比任何吆喝都管用。

账目摊在桌上：发电机日供电六度，水泵加砂滤罐日产净水四百升，自用五十升，余量三百五十升。修好的摩托改成了运水车。第一批客人是十公里外槐树聚落的采荒队，用两桶柴油和一箱罐头，换走了一百升净水。第二批来的直接是槐树聚落的管事，开口就想订长期供水。

"可以。"江图报价，"每周五百升，你们拿柴油、粮食或者零件结算。另外我要人——会焊工或者种过地的，来我这儿干活，管吃住，工钱用水和电结。"

管事走的时候，回头看了一眼那盏探照灯，看了很久。江图知道他在看什么——不是灯，是灯背后那套别人学不来的东西。

七天后，来了三个人：一个跛脚的老焊工，一对种过温室的夫妻。江图给他们分了活——焊工跟他扩建第二座砂滤罐，夫妻俩收拾加油站后面那片空地，试种他从废弃农科站里挖出的耐辐射麦种。

夜里，江图在本子上画下一个圈：储藏室、发电机房、水塔、田。圈外，他又画了一道更大的线。

墙外那片废墟他也算过：往东两公里的旧军营，围墙的预制水泥板大半还立着，拆下来运回来，就是现成的防御工事。掠夺者不会只来一次，下回可能是二十个人。趁人手刚够，得赶在他们回来之前把架子搭起来。

围墙。下一步，是围墙。
