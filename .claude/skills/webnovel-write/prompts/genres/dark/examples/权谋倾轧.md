# 权谋倾轧 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

沈砚被请进偏厅的时候，桌上已经摆好了三副茶盏。

三副，不是两副。这意味着今天的局，除了请他来的东府主事韩崇，还有第三个人要来。沈砚在门口停了半息，把这个细节记下了——韩崇没提第三个人，是不想让他有准备。那就当不知道。

"沈先生来得正好。"韩崇起身相迎，笑意妥帖，"听闻先生近日替西院清了一笔陈年旧账，手段干净，佩服。"

这不是夸奖，是试探。西院那笔账牵涉三家的利益，韩崇这句话是在问：你到底站哪边，动了谁的东西你自己清楚吗。沈砚落座，端起茶盏没喝："主事过誉。旧账而已，谁欠谁的，账本上写得清楚。我只是照账办事。"

翻译过来是：我不站队，我只认利益。韩崇眼底掠过一丝了然，也掠过一丝忌惮。

门外脚步声起。沈砚没有回头，只是慢慢把茶盏搁下——他已经知道，今天这厅里坐的每一个人，都揣着一把要落在别人身上的刀。而他要做的，是让这些刀，全都错开他，落到彼此身上。

## 核心场面

第三个人是南堂的钱敬，一进门就把矛头对准了沈砚。

"沈先生替西院办事，可知西院那批货，本是许了我南堂的？"钱敬把茶盏重重一放，"半路截胡，这规矩，先生怕是不懂。"

沈砚不慌。他懂钱敬的用意——钱敬要的不是货，是逼他表态，把他绑到西院这条船上，好让韩崇顺势收拾他们两个。这是个套，一个让他和西院捆死的套。

"钱堂主这话，"沈砚终于喝了一口茶，"该去问西院。货是西院的货，我只是经手。堂主的账，记在西院头上，找我，找错了门。"

一句话把自己摘了出去，还把火引回了西院和南堂之间。钱敬语塞。

这时沈砚话锋一转，看向一直含笑不语的韩崇："倒是有件事，我一直没想明白。西院那批货的路引，盖的是东府的印。若说货有问题，主事这枚印，怕是也脱不开干系。"

厅里骤然安静。这句话是把韩崇也拖下了水——路引确实是东府盖的，韩崇本想坐山观虎斗，让沈砚和钱敬相争，自己收渔利。可现在，沈砚把他架到了台面上。

韩崇端起茶盏，喝了一口，放下，看着窗外，久久没有说话。沈砚知道，这个沉默意味着韩崇正在重新算这盘账——原来最弱的那颗棋子，反手将了他一军。

## 收益兑现

三天后，南堂的钱敬因"私改路引"被东府问责，丢了半数货源。

这正是沈砚要的结果。那天在偏厅，他抛出"东府印"三个字，看似鲁莽，实则是给韩崇递了一把刀——韩崇要保自己的印不出事，唯一的办法就是把脏水泼到经手路引的南堂身上。沈砚只需点一句，剩下的，韩崇会自己动手。借刀杀人，刀是韩崇的手，血是钱敬的货，而沈砚从头到尾，一根手指都没脏。

韩崇设宴请他，这一次桌上只有两副茶盏。

"先生好算计。"韩崇亲自斟茶，语气里的忌惮已经不加掩饰，"钱敬到现在都以为，是我要动他。"

"主事说笑。"沈砚接过茶，这一回喝得很痛快，"我不过是把账算清了。谁的印，谁负责，天经地义。"

韩崇看着他，忽然笑了："西院那条线，如今空出来了。先生可有兴趣，替东府经手？"

这才是真正的收获。沈砚要的从来不是钱敬那批货，是这句话——从一个替人办事的经手人，变成东府认可的经手主家。棋子，成了执棋的人。他放下茶盏，拱手："敢不从命。"

走出东府大门，暮色四合。沈砚心里那张势力图已经重新排过：韩崇欠了他一个人情，钱敬和他结了梁子，西院还蒙在鼓里。三方的天平，因为今天这一局，全都朝他这边偏了一分。

一分不多。但他清楚，权谋的棋盘上，从来都是一分一分挪出来的。而下一局，就在西院交割那天。
