# 黑暗修仙 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

云岫把师兄的尸体翻过来，从他怀里摸出那枚储物戒。

戒指还带着体温。半个时辰前，这位大师兄还在指点她剑招，笑着说等她筑基就带她去南疆采药。现在他躺在秘境的碎石堆里，胸口一个焦黑的窟窿——不是死于秘境的凶兽，是死于同门的背后一剑。凶手已经跑了，只留下这具尸体，和尸体上没来得及拿走的东西。

云岫的手指没有抖。她很清楚这里的规矩：宗门外门弟子每年折损三成，活下来的从不是心软的那批。她把储物戒套上，神识探进去——三十七枚灵石，两瓶疗伤丹，还有半块淬骨石。够她把筑基前的最后一道瓶颈踹开。

她站起身，对着尸体拱了拱手。这不是虚情假意，是清算：师兄教过她三个月剑，这一拱，两清了。

远处传来脚步声，是回来收尸的人。云岫闪身躲进石缝。她不是怕，是在算——回来的若是杀人凶手，她现在动手，胜算不到三成；等他放松了，趁夜再动手，能到六成。

她选择等。

## 核心场面

三天后，云岫在宗门后山的丹房里，见到了那个凶手。

是同期的师姐辛媚，此刻正满脸堆笑地递来一杯灵茶："师妹这次秘境收获不小啊，都筑基了。"

云岫接过茶，没喝。她知道辛媚为什么找来——大师兄的储物戒里，还差半块淬骨石辛媚没拿到，那是她杀人的真正目的。辛媚以为凶案没有目击者，以为云岫什么都不知道。

"师姐这茶，"云岫把杯子搁在桌上，"是从大师兄那儿学的手艺吧？他生前最爱煮这个。"

辛媚脸上的笑僵了半瞬，又立刻续上："师妹说笑了，人死如灯灭，提他做什么。"

"是啊，死了就好办了。"云岫的声音很轻，"死人不会说，是谁在他背后补的那一剑。"

丹房里的空气凝住了。辛媚的手悄悄按向腰间的剑，云岫却先笑了："师姐别急着动手。我把那半块淬骨石，藏在了宗门的告密台下面。我要是今天回不去，明天长老就会收到一封信——信里有你剑上的血纹拓印。"

这是唬人的。血纹拓印她根本没取到。但辛媚不敢赌。杀人可以，被抓到证据是要被剥修为丢进锁灵渊的。

辛媚的手，一寸一寸地从剑柄上移开了。

## 收益兑现

那晚辛媚死在了自己的丹房里，死状是走火入魔。

云岫做得很干净。辛媚的疗伤丹被她换成了同色的引爆丹——修士运功疗伤时，这种丹药会在丹田里炸开，看上去和心浮气躁导致的走火入魔一模一样。她甚至不需要在场。她只需要在辛媚最放松、最需要疗伤的那一夜，让丹药自己完成剩下的事。

天亮后，云岫是第一个"发现"尸体的人。她哭得恰到好处，惊动了长老，也顺理成章地清点了辛媚的遗物——一柄中品法剑，六十余枚灵石，还有一本残缺的《淬骨真解》。储物袋里的东西比她预想的更多。辛媚这些年杀过的人，积攒的血财，如今全成了她的。

长老拍了拍她的肩，叹气说外门凶险，让她多加保重。云岫垂着眼应下，指尖在袖中摩挲那半块淬骨石——它从头到尾都在她自己身上，从没进过什么告密台。

回到自己的院子，她把辛媚的法剑拔出三寸。剑身映出她的脸，还是三个月前那个会为师兄之死红眼眶的少女模样。她盯着看了很久，然后把剑推回鞘中。

大师兄留下的账，清了。可她也清楚，今夜她多踏出的这一步，将来总要有人来向她讨。宗门的秋试还有半月——听说这一届的头名，能得到一枚破境的清心果。她需要那枚果子。而想要它的人，绝不止她一个。
