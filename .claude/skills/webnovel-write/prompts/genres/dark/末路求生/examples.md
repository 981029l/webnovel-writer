# 末路求生 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

罐头还剩四个，要撑七天。

孟野把这行字划在墙上，用的是烧焦的木炭。避难所是一间半塌的地下车库，靠一扇卷帘门和外面隔开，门缝下面塞着破棉絮，挡风也挡味。他们一共六个人，四个罐头，六个人，七天——这道算术他每天早上都要在心里过一遍，每过一遍，胃就往下沉一寸。

外面的世界已经安静了两个月。最初的混乱过去后，剩下的只有比混乱更可怕的东西：空荡的街道，被搬空的超市，还有偶尔从远处飘来的、说不清是人还是别的什么发出的声音。

"水管又不出水了。"角落里的老赵嗓子发哑，"接的那半桶，昨天用光了。"

孟野没说话。他掀开卷帘门一条缝，往外看。天是灰的，飘着细雨——雨水脏，但至少是水。他盘算着要不要拿桶出去接，接雨要冒的风险，和不接雨会渴死的确定，两边一样重。

雨越下越大。他回头看了看车库里六张脸，最后把那只空桶提了起来。

## 核心场面

出去接雨的第二天，新来的女人带来了一个消息，也带来了一道选择。

她叫林素，是孟野接雨时在巷口捡的，浑身湿透，冻得说不出话。孟野收留了她——多一张嘴，罐头就要提前一天见底，这笔账他当场就算清了，可他还是把人拉了进来。老赵为这个跟他吵了半宿。

现在林素缓过来了，说出了那个消息："往东三条街，有家药房，二楼的仓库还没被搬空。我亲眼看见的，一整箱药，还有消毒的东西。"

车库里瞬间安静。药——伤了两个月都没好利索的小周，正需要药。可东边那三条街，是出了名的死地，去过的人没一个回来。

"她可能在骗我们。"老赵盯着林素，"骗我们去送死，她好独吞这里的罐头。"

林素没辩解，只是把袖子撸起来，露出小臂上一道溃烂的伤："我也需要药。骗你们，对我有什么好处？"

孟野看着那道伤，又看了看角落里烧到迷糊的小周。去，可能全军覆没；不去，小周撑不过这周，罐头也一样撑不到那家药房被别人搬空。他做过太多这样的选择了——没有好的那个，只有坏的和更坏的那个。

他站起身，把撬棍别进腰后："我和林素去。老赵守门。天黑前我们不回来，你就当我们死了，把门焊死。"

## 收益兑现

他们回来的时候，天已经黑透，孟野的左肩插着半截钢筋。

但那只帆布包，是满的。

老赵开门的手在抖。孟野把包往地上一倒——七盒消炎药，两卷绷带，一整瓶碘伏，还有意外的收获：三袋没开封的压缩饼干。药房二楼那道死地传闻，原来是几具挡在楼梯口的尸体吓退了所有人，孟野和林素踩着那些尸体上去，才发现仓库根本没人守。

代价是真实的。孟野的肩膀被楼梯口的钢筋豁开，血流了一路；林素的脚崴了，是他半背半拖弄回来的。可当小周吃下第一片消炎药，当那三袋压缩饼干把"七天"重新算成了"十二天"，车库里六个人的呼吸，都比昨天松了一些。

孟野靠着墙坐下，让林素给他处理肩膀。碘伏浇上去的时候，他疼得倒抽冷气，却没出声——这点疼，比起白天在那栋楼里的每一秒，算不上什么。

"谢谢你信我。"林素低着头缠绷带。

"我没信你。"孟野盯着墙上那行新划的字，"我只是没别的选。"

他把"罐头还剩四个"划掉，重新写：饼干三袋，药七盒，撑十二天。写完他看了很久。十二天，比七天多五天。五天里会发生什么，他不知道。他只知道今晚，六个人都能睡个囫囵觉了。

卷帘门外，雨还在下。孟野闭上眼。明天的账，明天再算。
