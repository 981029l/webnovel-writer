# 规则生存流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

值班室的门被人从外面反锁了，钥匙孔里插着一张纸。

祁远把纸抽出来，油墨很新，边缘还带着裁切的毛刺。上面印了七条守则，标题是《夜班留守须知》。他今天下午才应聘进这家仓储站，人事说得轻描淡写：晚上一个人看场子，坐着就行。

第一条：22:00至05:00，任何情况下不得离开值班室。
第二条：如果听到有人敲窗，先看墙上的挂钟——整点敲，可以应；非整点敲，绝不能出声。
第三条：监控里出现第九个巡逻员时，立刻关掉所有灯。

祁远抬头看墙上的挂钟，21:58。他数了数监控画面，八个巡逻员，穿着一样的藏蓝制服，沿着货架之间的通道慢慢走。

他忽然意识到一件事：这家仓储站，白天他见过的工人，一共只有六个。

窗外传来一声轻响，像指节叩在玻璃上。祁远的目光钉在挂钟上，秒针刚刚跨过整点。

## 核心场面

敲窗声第二次响起的时候，是23:17。

不是整点。祁远死死咬住后槽牙，把到嘴边的"谁"咽了回去。守则第二条写得清楚——非整点敲，绝不能出声。他放轻呼吸，连椅子都不敢挪。

窗外那个影子贴着玻璃，缓慢地横移，像是在确认屋里有没有人。祁远盯着自己的手，指尖在发抖。他做了个决定：验证一下这条规则的边界。他捡起桌上的橡皮，轻轻弹到墙角——一点极轻的声响。

窗外的影子立刻停住了。

它转过来，正对着窗户。祁远的心跳几乎盖过了一切。他这才明白"出声"不只是说话，任何他制造的声响都算。那一瞬间他浑身的汗全冒了出来，后背贴着的椅背凉得刺骨。

影子在窗前停了足足两分钟，然后极不情愿地移走了。祁远瘫在椅子上，喉咙干得发疼。他拿起笔，在守则背面记下：出声=任何主动声响。代价一栏，他顿了顿，写下：差一点。

监控画面右下角，第七个巡逻员拐进了主通道。他数了一遍，还是八个。暂时。

## 收益兑现

凌晨三点，祁远把七条守则重新排了一遍。

他发现规则之间藏着一条暗线。第二条管敲窗，第三条管巡逻员数量，第五条说"05:00前不要相信挂钟以外的任何计时器"。三条规则都绕着"时间"打转——而值班室里唯一被守则认可的计时工具，就是墙上那口挂钟。

也就是说，只要盯死挂钟，他就能守住所有靠时间生效的规则。这是他今晚第一次觉得自己不是纯粹在挨。

监控里，那个多出来的第八个巡逻员走到镜头正下方，抬起了头。祁远的手指已经搭在了灯的总闸上——第三条，第九个出现就关灯。现在是第八个。他没动，只是把闸攥得更紧了些。

天光在05:01漫进窗户的时候，货架间的巡逻员只剩下六个。和白天一样多。

祁远长长地吐出一口气，起身去开门。门锁不知什么时候已经开了。他把那张守则仔细折好，塞进内袋——今晚活下来靠的就是它，明晚还得靠它。

只是走到门口他停住了。守则第七条他一整夜都没用上：天亮后，清点货架，若有一排货物是空的，立刻辞职，别回头。

他顺着通道望过去。最里面那一排货架，空的。
