# 诡局推演流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

墙上贴着六条守则，其中一条被人用红笔划掉了。

裴知把这个细节记在了心里。九个人被关进这栋废弃疗养院，每人分到一份一模一样的守则，唯独墙上这份，第四条被划了。划线的笔迹很用力，纸都破了。

"谁划的？"她问。没人应声。

第四条写着：每晚熄灯后，清点在场人数，若多出一人，装作没看见。

裴知盯着那道红痕。有人不想让别人遵守这一条——或者相反，有人试过遵守，出了事，才回来划掉警告后人。两种可能，指向完全相反的结论。她需要更多信息才能判断。

她转向那个自称第一天就来的男人，姓宋："墙上这份守则，昨晚在这儿的时候，第四条划了没有？"

宋沉默了两秒。"划了。"

裴知记下：至少昨天之前，划线已经存在。那么划线的人，比宋更早进来——可宋说自己是第一批。矛盾出现了。她要么在撒谎的人堆里，要么漏掉了一个人。

## 核心场面

熄灯前，裴知把九个人聚到大厅，做了件所有人都没想到的事——她要每个人报出自己进来的具体时间。

"这有什么用？"宋不耐烦。

"第四条说熄灯后多出一人要装作没看见。"裴知语速很平，"可如果一开始的人数就是错的呢？我们默认是九个，因为我们数了九次都是九。但我们从没在熄灯的那一刻数过。"

大厅安静下来。她继续往下推："守则第二条，熄灯时间由大厅的挂钟决定。第六条，任何人不得调整挂钟。看起来这两条在保护计时的准确。但换个角度——如果挂钟被人动过，熄灯的'那一刻'就是假的，第四条的清点也就永远抓不到那个多出来的人。"

"你的意思是，"一个扎马尾的女孩声音发紧，"有人靠改钟，把自己藏在人数里？"

"我不确定。"裴知看向宋，"但我确定一件事。宋先生说他是第一批进来的，可墙上的红线比他更早。要么他记错了时间——要么，划线的那个人，从一开始就没被我们算进九个里。"

宋的脸色变了。挂钟在这时敲响，比所有人手表都快了七分钟。

## 收益兑现

裴知让所有人对表，果然，大厅的挂钟快了七分钟。

推论闭合了。她把逻辑链摆给众人看：挂钟被人为拨快，是为了让"熄灯时刻"提前到真正熄灯之前——在那七分钟的空档里，第十个人可以混进队伍，而第四条的清点因为时间错位永远数不到他。红笔划掉第四条的人，是唯一识破这一点的前住户，他用划线告诉后来者：别信这条清点规则，它从设计上就抓不到真凶。

"所以现在有两个办法。"裴知的声音在空荡的大厅里很清晰，"要么把挂钟拨回准点，让第四条重新生效——但我们不知道准点是几点。要么，我们绕过挂钟，用别的方式在真正熄灯的瞬间清点。"

她选了后者。九个人手拉手围成一圈，谁都不许松开。灯灭的刹那，她一个个数过去。

数到第十只手的时候，那只手是凉的。

宋的呼吸骤然停住。裴知没有松手，也没有回头，只是极轻地说："找到了。红线没骗我们——从进来的第一天起，我们就一直是十个人。"

黑暗里，那第十个人开口了，声音像是从很远的地方传来："你比划线那个聪明。他只想到了钟。"
