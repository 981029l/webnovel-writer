# 密室调查流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

门在身后合上，晏清听见锁舌落进凹槽的轻响。

她转身试了试把手，纹丝不动。这是一间没有窗户的公寓，玄关的鞋柜上摆着四双拖鞋，整整齐齐，鞋头朝外。她数了数，四双。可这套房子的户型图贴在门后，标注是三居室——按常理，住三个人。

客厅的挂钟停在2:47。她低头看手表，现在是23:10。两个时间对不上，而且差得离谱。她没有急着往里走，先站在原地扫了一圈：茶几上有半杯水，水面还在轻微晃动，说明不久前有人碰过；沙发的坐垫塌陷着一个人形的凹痕，位置偏左；空气里有一股很淡的消毒水味，从走廊尽头飘过来。

四双拖鞋，三居室，晃动的水，还没散去的体温痕迹。

晏清在手机备忘录里敲下第一行字：这里刚才有人。她抬头望向那条飘着消毒水味的走廊，尽头的门虚掩着，门缝里透出一线冷白的光。

## 核心场面

晏清先查了客厅。

茶几下压着一沓外卖单，最上面一张的日期是三天前，收件人写着"陈"。她把单子一张张翻过去，越往下日期越早，可到了第五张，收件人突然变成了"李"。同一个地址，两个姓。她把这条记进备忘录，没下结论。

她走到那间偏卧，门推开时发出一声黏腻的摩擦。房间里只有一张床，床头柜上摆着一部老式座机，红色的留言灯在闪。她按下播放键。

"……三天了，别再打这个号码了。"一个沙哑的女声，背景里有滴水声，"她已经不在这儿了。"

留言到此为止。晏清盯着座机看了几秒，伸手摸了摸床单——冰凉，而且潮湿，像是被水浸过又没干透。她掀开床单，床垫上有一道深色的印记，形状狭长，从床头一直拖到床尾，末端指向墙角的衣柜。

拖拽痕。她的心沉了一下。

衣柜的门把手上缠着一根头发，很长。她没有立刻去开柜子，而是退后一步，重新看整个房间——为什么一间刚才还有人活动的公寓，会有一道通向衣柜的拖拽痕？消毒水味，是从这间飘出去的，还是飘进来的？

她伸手，握住了衣柜的把手。

## 收益兑现

衣柜是空的。

但空得不对。柜子的进深比她目测的浅了一截，后壁的木板颜色也比两侧新。晏清用指节敲了敲，声音是空的——后面还有空间。她沿着木板边缘摸了一圈，在右下角找到一个几乎看不见的凹槽，用力一推，整块后壁向内滑开。

一条向下的窄梯，消毒水味从下面涌上来，浓得呛人。

所有线索在这一刻归了位。四双拖鞋对应四个人，可户型只写三居——因为第四个人的位置，从来不在图纸上，而在楼下这个暗层里。外卖单上的两个姓，是先后住进来的两拨人；停摆的挂钟指着2:47，是这套房子里"时间"被冻住的那一刻。座机留言里那句"她已经不在这儿了"，此刻有了最不祥的含义。

晏清没有马上下去。她先把整理好的线索发给了自己的第二个手机号——如果她出不去，至少有人能接着查。做完这些，她才踩上第一级台阶。

木梯在脚下发出呻吟。往下走了七级，消毒水味里混进了另一种气味，甜腻的、金属的。楼梯尽头是一扇铁门，门是从里面反锁的——也就是说，锁门的人，还在下面。

她的手停在门上。备忘录的最后一行，她写道：这不是一套公寓，是一个盖子。而真正的房间，在盖子底下。
