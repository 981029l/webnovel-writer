# 天灾求生流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

温度计挂在阳台外墙，早上七点，指针停在零下十九度。

顾建国记下数字，翻开本子。前天零下十三，昨天零下十六，今天零下十九——每天往下掉三度，一点没乱。气象台还在播"寒潮短期过境，预计回暖"，可他知道回不了暖了。这场极寒是奔着把整座江城冻穿去的，按这个速度，二十天后就是零下八十。

他没时间管别人信不信。

清单摊在桌上，划掉的项目已经过半：地窖挖好了，两米深，四壁夯了黏土；柴火囤了四吨，垛在楼道尽头封死的储物间；窗户全钉了双层木板，中间塞旧棉被；土灶和铁皮烟囱昨天装好，试烧过，不倒烟。

还差三样：储水、封门缝、备融雪的滤网。

妻子端着热水进来，看他又在核表，忍不住劝："楼下都说供暖公司加了煤，撑得住的。"

顾建国没抬头："管道到零下四十就冻裂。到那天，供暖公司自己先散。"他把最后半桶水倒进地窖的储水罐，"今天把北阳台的水管缠上棉套，明天我去五金市场，趁还开门，把最后两卷保温棉扫回来。"

妻子没再劝。这些年家里大事小事，他算准的时候多。她放下水杯，默默去翻装棉套的袋子。

窗外，第一批往南撤的车已经堵在了主干道上。

## 核心场面

零下四十一度那天夜里，江城的电网塌了。

不是停电，是塌——过载的变电站一个接一个跳闸，整片城区的灯像被人从北到南依次摁灭。水泵停转，高层住户拧开龙头只有冰碴；电梯停在半空；冰箱化了又冻。顾建国站在自家封死的窗后，从木板缝里看出去，对面楼一格格暗下去，只剩手电的光在楼道里乱晃。

他家里，土灶的火正旺。

麻烦是后半夜来的。楼下传来砸门声，混着哭喊——三户邻居扛不住了，听说他有柴有火，来借。为首的是隔壁老陈，前些天还笑他"挖地窖神经病"。

顾建国隔着门谈："柴我分你们一些，火你们自己在楼道背风处生。人不能都进来，地窖就这么大，进来挤，热量散得比省的快，谁都活不成。"

老陈急了，捶门更狠。顾建国抄起门后的铁棍，声音沉下来："我给的是活路，不是让你们把我一家拖下水。柴在门口的编织袋里，一户一捆，够烧到天亮。天亮了想活命，就照我说的，去地下车库，那儿背风、聚温。"

砸门声停了。片刻，楼道里响起搬柴的窸窣声，然后是脚步远去。妻子在灶边看着他，轻声问："车库那招，真管用？"

"管用。地下车库在冻土层以下，三十户人挤在一起，人自己就是炉子。"顾建国往灶里添了一根柴，"我上个月就量过那儿的温度。"火苗蹿起来，映着墙上那张越划越短的清单。窗外的温度计，指针已经探到零下四十三。

## 收益兑现

极寒的第二十六天，江城最低温冲到零下六十一，随后开始缓慢回升。挺过来的人不多。

顾建国的地窖里，账目一清二楚：入冬前囤的四吨柴，用掉两吨八，剩下一吨二，足够撑到彻底转暖；储水罐两吨,配着融雪滤网,一口没缺过；粮食按两人份备的三百天量,才动了零头。

真正的收益是这些天攒下的东西。

老陈活下来了,带着一家三口。开春前他敲开顾建国的门,搓着冻裂的手:"老顾,那晚要不是你把我们赶去车库,我们一家早没了。往后……你说怎么干,我们就怎么干。"跟着来的还有另外两户,都是那晚照他说的话保住命的人。

顾建国收下了,规矩照旧摆在明面上:出力才有份。会电工的老陈负责修复太阳能板,楼上的年轻人跟他去清理废墟里的物资,女人们轮班看火、化雪、清点存粮。一个各扫门前雪的单元楼,冻出了一支听他指挥的队伍。

他站在楼顶,看着冰封的江城在灰白的天光里一点点显出轮廓。远处主干道上,那些当初往南撤的车,还有大半停在原地,再没动过。

顾建国翻开新的一页本子,写下开春后的第一项:融雪季要防的,是洪水。

天灾一场接一场,但他手上有账,心里有数。
