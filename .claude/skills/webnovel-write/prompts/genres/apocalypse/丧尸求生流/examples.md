# 丧尸求生流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

超市卷帘门被撬开一条缝的时候，秦烈已经在货架后蹲了十分钟。

外面进来三只，普通尸，动作僵，循声型。他捏了捏手里的消防斧——重量趁手，但挥一次的动静能把半条街的尸引来。腰上还别着一把改短的钢钎，无声，适合一对一。

末世第十一天。他的账很清楚：背包里两瓶水、六包方便面、半盒感冒药；打火机一个；一级晶核九枚，还差六枚，右臂的强化异能就能进到第二阶。粮不算多，但撑到城西的粮库不成问题——前提是今天能从这家超市拿到货架深处那几箱压缩饼干。前天他从别的幸存者嘴里换来的情报说，这家超市开市第一天就被封了卷帘门，里面的货动都没动过。为这条情报他付了一包方便面，现在看，值。

第一只尸拖着腿晃过货架口。秦烈从侧面起身，钢钎斜着捅进它的后脑，手腕一拧，抽出。尸体软下去，他伸手接住，慢慢放平——不能有声音。

指尖探进颅骨裂口，摸出一枚指甲盖大的灰白晶核。

十枚了。

剩下两只还在门口打转。秦烈把晶核收进贴身的布袋，提着钢钎绕向下一条货架通道。

## 核心场面

尸潮是下午三点漫过街口的。

不是几十只，是整条主干道望不到尾，前排的尸被后面的推得踉跄，铺面而来像一堵会动的墙。地面隔着两层楼都能感到细密的震颤。秦烈从超市二楼窗口看了一眼，立刻收回头——他的撤退路线被断了，唯一的活路是穿过后巷，翻进隔壁五金城，走天台。

后巷里有七只。硬闯。他把背包的胸扣和腰扣全部收紧，深吸一口气。

他把消防斧换到右手，强化过的手臂肌肉绷起。第一斧横扫，最近那只的颅骨整个凹进去；第二只扑上来，他侧身让过，斧背反手砸在它太阳穴上。第三第四只并排堵路，秦烈矮身撞进去，左手钢钎捅穿一个眼窝，右臂发力把另一只整个掀翻在墙上，补一斧。

第五只不一样。皮肤泛着青黑，扑击的速度快了一倍——变异体。

斧刃砍上去只入了半寸。秦烈心里一沉，弃斧后撤两步，变异体扑空的瞬间，他从背后拽下钢钎，全身重量压上去，从它下颌斜着钉进颅腔。

变异体抽搐着倒下。后巷尽头，尸潮的前锋已经拐进来了。

秦烈拔钎，掰开变异体的颅骨抓出晶核——泛蓝，二级——揣进怀里就跑。翻上五金城围墙的瞬间，第一只尸的指甲擦着他的鞋底抓空。

## 收益兑现

天黑前，秦烈在五金城天台的水箱房里落了脚，反锁铁门，开始盘账。

今日入库：压缩饼干四箱、瓶装水两提、工具区顺的一把长柄羊角锤和两卷铁丝。晶核收入：一级六枚，二级一枚。损耗：消防斧丢在后巷，左小臂被货架划了道口子，已用感冒药盒里的酒精棉处理。账算下来，赚得不算少，但斧头的教训他记下了——下次进货区，先给自己备一件趁手的备用近战。

一级晶核凑到十五枚，够了。

他盘腿坐下，把晶核一枚枚攥进右手。熟悉的热流从掌心钻进手臂，肌肉纤维像被重新编织，酸胀过后是一种沉甸甸的充实感。轮到那枚二级晶核时，热流猛地翻了倍，一路烧到肩背——

强化范围从右臂扩展到了整个上半身。

秦烈睁开眼，随手握住旁边的钢管，五指收紧。钢管表面陷下五道清晰的指痕。

他试着空挥了一下羊角锤，破风声又快又沉。放在昨天，后巷那只变异体能逼他弃斧；放在现在，一锤就够。

水箱房外，远处的尸潮还在街面上漫游。秦烈啃了半块压缩饼干，把明天的路线在地图上画出来：城西粮库，直线两公里，沿途三个待搜刮点。头两个是药店和五金分店，顺路清掉；第三个是家户外用品店，运气好能捞到弩——无声武器，尸潮天里比枪金贵。

比昨天更能打，比昨天更有底。他吹熄蜡烛，睡得很稳。
