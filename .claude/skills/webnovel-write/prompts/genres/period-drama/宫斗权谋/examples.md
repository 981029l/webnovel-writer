# 宫斗权谋 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

沈知微入宫的第七日，头一回被点名去凤仪宫请安。

殿内熏着上好的沉水香，皇后高坐上首，指尖捻着一串佛珠。众嫔妃依位次而坐，沈知微一个小小的正七品选侍，站在最末，连绣墩都没有。

"新进的妹妹里，就数沈选侍出挑。"说话的是丽妃，一身石榴红宫装，笑吟吟地打量她，"听闻昨夜陛下驾临撷芳斋，坐了足足一个时辰？"

满殿的目光霎时都压了过来。这话是刀——认了，是恃宠张扬；不认，是欺瞒。

沈知微屈膝一福，垂着眼："回丽妃娘娘，陛下昨夜是来看撷芳斋新移的那几株绿萼梅，说是先皇后生前最爱。臣妾不过在旁伺候茶水，不敢居功。"

殿中静了一瞬。先皇后是当今皇后的胞姐——这话一出，恩宠成了追思，谁再往下挖，便是对先皇后不敬。

皇后捻珠的手停了停，抬眼多看了她一眼："你倒是个明白孩子。赐座。"

宫女搬来绣墩。沈知微谢恩落座，眼观鼻，鼻观心。她知道，从这一刻起，这满殿的人里，至少有三个记住了她。

## 核心场面

腊月初八，德妃宫里的掌事姑姑亲自送来一匣血燕，说是德妃娘娘体恤新人。

贴身宫女青杏欢喜地要收，沈知微却道："先搁着。"

当夜她翻来覆去地想：德妃与她素无往来，无功受禄，必有蹊跷。三日后，太后凤体违和，阖宫嫔妃侍疾。果然有人"无意"提起，沈选侍前几日得了上好的血燕，怎不见孝敬太后？

若她献上去，燕窝里但凡查出半点不妥，便是谋害太后的死罪；若她私自留用，便是不孝不敬。

沈知微跪在太后榻前，从袖中取出一份礼单："回太后，那匣血燕，臣妾三日前已原封送去了尚食局,请御医验看成色——臣妾位卑，得了贵重之物不敢擅用，想着验明了再孝敬太后，才是稳妥。"

尚食局的记档做不得假。御医验出，那匣血燕中掺了微量红花。

殿内霎时死寂。太后撑起身子，目光缓缓扫向侍立一旁的德妃："好一匣'体恤新人'的血燕。"

德妃扑通跪下，鬓上的珠钗都在颤："太后明鉴，臣妾冤枉——"

"冤不冤枉，"太后淡淡道，"慎刑司问过送礼的人，便知道了。"

沈知微伏在地上，眉眼低垂，无人看见她眼底一闪而过的冷光。这一局，是她拿自己做的饵。

## 收益兑现

德妃降为德嫔，禁足三月，宫权交还皇后。腊月十五，圣旨到了撷芳斋。

"选侍沈氏，恭谨明慧，晋正五品才人，赐居长宜殿。"

宣旨太监笑得殷勤："沈才人，长宜殿离乾元殿可只隔着一道花园，这份体面，宫里多少年没有过了。"

沈知微接旨谢恩，命青杏封了赏银。搬宫那日，来道贺的人几乎踏破门槛——上月还对她爱答不理的婉贵人，捧着亲手绣的帕子等了半个时辰；连皇后宫里的掌事姑姑，也代皇后送来一柄玉如意，话里话外，是招揽之意。

夜里，青杏一面替她拆髻，一面咋舌："才入宫两个月，主子就从选侍升到才人，连跳三级，奴婢听说丽妃娘娘气得摔了茶盏。"

"摔盏是做给人看的。"沈知微望着铜镜，慢慢卸下耳珰，"她今日午后就递了帖子，约本宫赏梅。"

"那主子去么？"

"去。"她把耳珰搁进妆匣，合上盖子，声音很轻，"德嫔倒了，丽妃独大，皇后睡不安稳，正缺一把趁手的刀。本宫要让她们两个都以为——这把刀，握在自己手里。"

窗外雪落无声。长宜殿的灯，亮到了很晚。
