# 都市成长 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

陈屿的房东在早上七点发来消息：房子卖了，月底前搬走。

他盯着手机看了半天，煎饼摊老板催了两声"要不要辣"，才回过神。这间隔断房他住了三年，走路十分钟到公司，房租每月一千八，是他到手工资六千二里唯一还能忍受的一项。

上班的路上，他挤2号线换6号线，在车厢里刷同城租房。同地段的整租涨到了四千，隔断也要两千五往上。他算了一笔账：房租两千五，吃饭一千五，通勤三百，给老家寄一千，剩下的钱连一场感冒都生不起。

到了工位，他没急着搬家的事。手边这个季度报表拖了三天，主管早上开会又不点名地敲打了一句"有的人手头的活儿该动动了"。

陈屿把租房软件关了，打开报表。他忽然想起入职时同批进来的那个女生，去年跳槽去了一家做数据产品的公司，薪资翻了一倍。当时他觉得那种活儿门槛高，自己碰不了。

中午吃饭，他没跟同事下楼，一个人在工位上啃包子，打开了那家公司的招聘页面。任职要求里有一半的词他看不懂。

他把那些词一个一个抄进了备忘录。啃完最后一口包子，他想，看不懂就学。反正月底要搬家，日子已经不能更糟了。

## 核心场面

三个月后，陈屿投出去的第十一份简历，终于收到了面试通知。

那家公司在城东，他请了半天假过去。面试官是个三十出头的技术主管，翻着他的简历，语气平淡："你之前一直做行政报表，跨度有点大。你觉得你凭什么能做数据分析？"

这句话陈屿在心里演练过无数遍。他没有背那些漂亮话，而是从包里拿出一台笔记本，打开一个文件夹。

"这是我这三个月做的东西。"他把屏幕转向对方，"我把前公司三年的公开经营数据扒下来，自己搭了个分析模型，做了六份复盘报告。这一份，是预测他们某条产品线会在第二季度下滑——后来真的下滑了，我事后核对过。"

面试官翻报告的手停了下来。

"你自学的？"

"晚上和周末。"陈屿说，"我知道我起点低，专业的人一眼能看出我很多地方不规范。但我想让您看到的不是我现在有多好，是我三个月能走多远。"

办公室安静了几秒。面试官合上笔记本，抬头看他："你这个下滑预测，模型逻辑给我讲一遍。讲对了，下一轮我给你约在这周。"

陈屿深吸一口气，把准备了三个月的东西，一句一句讲了出来。他的手心全是汗，声音却没抖。讲到一半，他看见对方开始点头。

## 收益兑现

入职通知发来的那天，陈屿正在新租的房子里拧灯泡。

新公司在城东，他搬到了附近一个老小区，整租一室一厅，两千九。虽然更贵了，但他不用再和三个陌生人共用一个卫生间，窗户朝南，下午有太阳。

薪资邮件写着：月薪一万一，试用期三个月。比原来翻了将近一倍。

他坐在还没铺好的地板上，给老家打了个电话。母亲在那头絮絮叨叨问工作累不累、吃得好不好，末了小声说："你上个月寄回来的钱，妈没舍得花，给你存着。"

"妈，下个月我多寄点。"陈屿说，"我换工作了，工资涨了。"

电话那头愣了一下，然后是压低的、有点哽咽的笑："换工作了？累不累啊……"

"不累。"他望着窗外，夕阳把小区的旧墙染成暖黄色，"妈，我现在做的事，是我自己想做的。"

挂了电话，他把最后一颗灯泡拧上。灯亮了，照着满地的纸箱和一台旧笔记本。

他知道这一万一还不算多，城东的房租、往后的日子、更难的项目，全都在前头等着。但他也知道，三个月前那个在地铁上不敢投简历的自己，已经被他甩在身后了。

他打开笔记本，新建了一个文件夹，命名为"入职第一周"。然后开始学起了明天要用的新工具。
