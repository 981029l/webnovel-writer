# 都市异能 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

晚高峰的3号线，林澈的太阳穴又开始发烫。

这是三周前那场高烧留下的后遗症——只要皮肤接触到别人，他就能"听"到对方最强烈的那个念头。不是读心，更像收音机漏出来的杂音，一天下来脑袋疼得像被灌了水泥。所以他现在戴手套，七月天，全车厢就他一个戴手套的。

车到滨江路站，人潮往里挤，一个拎着帆布包的中年男人贴到了他旁边。晃动中，男人的手背蹭到了林澈的脖子。

"——引爆器在包底，倒数第三站。"

林澈浑身的汗毛瞬间竖了起来。

他不动声色地侧过头。男人低着头，额角全是汗，帆布包抱在胸前，抱得死紧。倒数第三站，是换乘枢纽站，晚高峰人流量全线第一。

报警？说什么，说我摸了他一下听到他想炸地铁？林澈的心脏咚咚地撞。还有四站。他看了一眼车厢顶的监控，又看了一眼男人抱包的手，慢慢摘下了右手的手套。

房租还欠着，明早九点还要打卡上班。但此刻这节车厢里,只有他一个人知道要出事。

林澈深吸一口气，往男人身边挪了半步。

## 核心场面

"哥们，借过一下。"

林澈挤过去的瞬间，右手"不小心"扶上了男人的手腕。念头的洪流猛地灌进来——不是狂热，是绝望：被裁员、妻子的医药费、一个陌生号码打来的电话、"办成了给你八十万"。

不是主谋，是被人当枪使的。而且——林澈捕捉到最关键的一帧——引爆器要用那个号码回拨激活，男人自己控制不了。

"你被骗了。"林澈压低声音，手没松开，"给你打电话的人，不会给你八十万。他们要的是你和这一车人一起消失，死无对证。"

男人猛地抬头，瞳孔骤缩："你、你是谁——"

"你女儿今年高三，对吧。"林澈盯着他的眼睛，把刚才"听"到的念头一条条抛出来，"你想着办完这单，钱打给你老婆治病，你去自首。醒醒吧,包一响,你就是唯一的凶手，你家里人一分钱拿不到，还要背一辈子骂名。"

男人的手开始抖，抱着包，眼泪一下子涌出来。

"下一站下车,跟我走。"林澈扶住他，"把电话号码交给警察，你是被胁迫的，还有机会。"

列车进站。两人一前一后走出车门的第七分钟，站警接管了帆布包。排爆确认：包内装置真实有效，遥控激活。

做完笔录出来已是深夜。林澈站在派出所门口揉太阳穴，一个穿灰色夹克的女人递来一张没有任何头衔的名片："林先生，接触性读取，覆盖挺完整。我们'灯塔办'的人观察你两周了。聊聊？"

## 收益兑现

灯塔办的驻点在一栋写字楼的十四层，门牌写着"城市数据研究中心"。

"编外协查员，B级待遇。"灰夹克女人姓乔，把一份协议推过来，"每月基础津贴一万五，单次任务另算。地铁这单，定性为阻止重大公共安全事件，专项奖励八万。"

林澈捏着笔的手顿了顿。八万。他上一份工作月薪七千，房租押一付三差点没凑齐。

"当然，有约束。"乔姐指了指协议第三页，"能力使用要报备，禁止用于商业窃密和赌博，每月体检——你这个能力走神经系统，过载会造成不可逆损伤。我们的医疗组会教你控制阈值，往后不用再靠戴手套硬扛。"

一周后，林澈第一次上训练课。指导员教他把"收音机"的旋钮找出来——原来杂音是可以关小的，接触时主动聚焦，才定向读取。课程结束时，他摘着手套在楼下买了杯冰豆浆，接过找零，指尖碰到摊主的手。

什么都没涌进来。安静的。

他站在夏夜的街边，差点笑出声。三周了，他第一次敢光着手碰人。

手机震动，乔姐发来第一个正式任务：本市两个月内七起"梦游式"高空作案，嫌疑人清醒后均无记忆，怀疑有异能者介入。附言只有一句：这次的对手，也有能力。

林澈灌了口豆浆，把手套塞进了口袋。回消息：明晚下班后到岗——白天他还得上班，房租，总归还是要交的。
