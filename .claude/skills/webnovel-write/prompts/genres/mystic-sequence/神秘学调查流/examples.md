# 神秘学调查流 风格范文

以下片段为文风示范，人物、地名、途径与组织名均为演示虚构，禁止照抄进正文。

## 开篇

委托信是随晨报一起送来的，压在门缝下，没有署名。

信里只写了一件事：栗树巷十七号的一家四口，同一夜做了同一个梦——梦见自己站在一片没有星星的海边，海里伸出无数只手向他们招手。醒来后，最小的女儿开始梦游，每夜准点走到临街的窗前，抬手，像要推开一扇并不存在的门。

调查员莫兰读完信，先做了两件平常事：查这家人的底细，再查栗树巷的地契沿革。前者干净得反常，一家规矩的钟表商；后者却有意思——十七号那栋楼建于四十年前，地基下压着一座更早的私人礼拜堂，礼拜堂在一场无人生还的火灾后被填平。

她带上惯用的三样东西：一副塔罗、一枚灵摆，还有翻旧了的笔记本。

到了栗树巷十七号，莫兰没急着谈梦。她先看那扇临街的窗——女孩每夜抬手要推的方向。窗玻璃很旧，边角泛着一层几乎看不见的盐霜，用指甲刮下来，尝一点，是海盐。可栗树巷离海有二十里，这栋楼的窗，四十年没见过海。

“做梦之前，家里有没有添过什么旧物？”她问女主人。

女主人想了想：“上个月……先生从旧货市场淘回一面镜子，说是老礼拜堂的东西。挂在了女儿房里。”

莫兰在笔记本上写下一行：镜子。海盐。填平的礼拜堂。三样东西，隔着四十年，指向同一个地方。

## 核心场面

灵摆在那面旧镜前，转出了它不该转的方向。

按规矩，莫兰先问了三个校验问题：今天是不是晴天，她的名字是不是莫兰，她左手是不是握着灵摆。三次，铜锤都规矩地划出“是”的直线。可当她问“镜子里有没有东西”，灵摆猛地绕起圈来——不是回答，是被牵引，像有什么东西隔着玻璃拽住了铜锤。

她立刻收线，退开半步。这不是普通的招灵器物。她放开灵视，看向镜面。

镜子照不出房间，照出的是一片深黑的海。海面之下，有极多的、苍白的手，正朝着镜子这一侧缓慢地伸。它们够不到玻璃，却在够那个每夜走到窗前的女孩——女孩推的不是窗，是镜子里那扇门。

莫兰翻开笔记本，把碎片拼起来。四十年前的礼拜堂，供奉的不是正统的神。火灾不是意外，是当年的教会裁判所动的手，他们烧了礼拜堂，却漏了这面充当“门”的镜子。镜子被埋、被挖出、辗转进了旧货市场，如今挂回了原地附近——它认得回家的路，也认得能替它开门的人。

“把镜子摘下来。”她对闻声赶来的女主人说，语气不容置疑，“别照它，用布蒙着摘。你女儿今晚推开那扇门，进去的不是梦。”

她没有当场砸镜子——砸开一扇正对着“海”的门，是蠢事。她用盐线在镜框四周缠了三圈，又在女孩床头放了一枚校验过的护符，暂时压住那片海的招手。真正要处理这面镜子的，是评议会的封存组，不是她一个人。

## 收益兑现

封存组连夜带走了那面镜子。莫兰站在空出来的墙前，把最后一块拼图补上。

那家人的梦、女孩的梦游、窗上的海盐，全都对上了。她在结案报告里写道：涉案器物为“无星之海”相关造物，具备低强度的门户特性，牵引特定睡眠者向其显化的空间行进；处置措施为盐封、转运、评议会封存。附注一栏，她添了一句：建议核查四十年前礼拜堂火灾的裁判所卷宗——那场火，可能没烧干净。

她拿到的报酬是两样。一样是评议会记入档案的一次结案，换来能调阅二级封存卷宗的权限；另一样，是封存组组长临走时递给她的半页残纸，是从镜框夹层里找出来的。

残纸上是四十年前的一份名单，礼拜堂信徒的签名。名单末尾，有一个名字被人用力划去，却依然认得出——正是把镜子从旧货市场淘回来的那位钟表商先生的姓氏。

莫兰盯着那个划痕看了很久。这一家人不是无辜撞上旧物的路人。四十年前那场火里，有一个人活了下来，改了名字，等着某一天把镜子接回家。

她合上报告，却没有合上笔记本。栗树巷的案子结了，可它撬开的缝里，露出的是一桩更旧、更大的东西——那座填平的礼拜堂，那片无星之海，那些当年逃过火刑的信徒，如今散在城里的哪些角落。

窗外天光渐亮。莫兰在新的一页上写下第一行字：无星之海，信徒名单，第一名，钟表商。然后她起身，去申请那份四十年前的卷宗。谜面解开了一个，谜底又退远了一层。这正是她留在这一行的理由。
