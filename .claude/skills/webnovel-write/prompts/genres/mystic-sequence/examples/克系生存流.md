# 克系生存流 风格范文

以下片段为文风示范，人物、地名、途径与组织名均为演示虚构，禁止照抄进正文。

## 开篇

裴远抵达灰港镇的第三天，就明白自己不该来。

镇子建在礁岩上，家家户户的门槛都刻着同一种螺旋纹路。镇上的人对陌生人客气得过了头，说话时总慢半拍，像是在等某个听不见的声音替他们回答。港湾里停着许多船，桅杆上没有一面帆——问起来，渔民只说“出海的日子还没到”，却没人说得清那是哪一天。

他是替一家海事保险公司来查一桩旧事的。四年前，一整支船队从灰港出海，无一返航，档案上写着“遭遇风暴”。可裴远查过那晚的气象记录，海面平静得像一块玻璃。

第三天夜里，他被一种声音弄醒。不是海浪，是许多人一起低吟的调子，从礁岩下面传上来，隔着几十尺的岩层，却清晰得像贴在耳边。那调子里没有一个字是他认得的语言，但他躺在床上，竟渐渐“懂”了几分意思——那是在数着日子，数着某个即将到来的涨潮。

他猛地坐起，掐灭了这份理解，逼自己去想别的：保险单的条款，回程的车票，母亲寄来的信。心跳很久才平复下来。

天亮后，他在洗脸的水盆里看见自己的倒影。眼白上，多了几丝极细的、暗红的血丝，排列成一个很小的螺旋。裴远盯着它看了三秒，然后泼掉了盆里的水。

昨夜那点“听懂”，是要付利息的。他记下时间，在笔记本上写：第一次污染，来源不明的吟诵，症状——旋纹血丝，认知残留。然后他开始收拾行李。这地方，多待一天，就多欠一天的账。

## 核心场面

裴远没能立刻走成。前往车站的唯一一条山路，一夜之间被落石堵死了——镇上人说，这是“海不让客人走”的意思。

他决定在潮汛之前弄清真相，再想办法脱身。白天，他撬开了镇公所废弃的档案室，翻出四年前那支船队的名册。名册末尾附着一张手绘的航路图，终点不是任何海图上有的地方，而是一处标着螺旋符号的坐标。图的背面写着一行字：献者归于深处，镇子换一轮太平。

他懂了。四年一度，灰港把一船人“献”出去，换来四年的风调雨顺。四年前是一整支船队，而这一次——他数了数镇上异常安静的门户——这一次的“献者”，凑不齐了。所以他们对陌生人格外客气。

他没有去闯，也没有想过战胜礁岩下面的那个东西。他很清楚，那东西不是能打赢的目标，甚至不该被完整地看一眼。他要做的只有一件事：在涨潮之前，把自己从“献者”名单上抹掉。

镇上人认的不是脸，是那道刻在门槛上的螺旋纹——被纹路“认领”的人，才会在潮汛夜自己走向海里。裴远回到住处，用小刀把自己门槛上的螺旋纹一寸寸削平，又在削过的地方涂满灰港人最忌讳的东西：灶膛里的柴灰。档案里提过一句，献祭忌“火之余烬”，因为深处的东西厌恶陆地上的火。

他不知道这管不管用。但这是他手里唯一的牌。做完，他吹灭灯，坐在墙角，握着那把小刀，等天亮，也等涨潮。

## 收益兑现

涨潮在后半夜来了。

裴远听见镇上的门一扇扇打开，无数只赤脚踏在石板路上，朝着港口，走得整整齐齐，没有一个人说话。那吟诵又响起来，比第一夜近了十倍，几乎要把他的名字从喉咙里勾出去。他咬着一块塞进嘴里的柴灰布，死死抵住那股想要起身、想要加入队伍、想要走进海里的冲动。指甲抠进掌心，血流下来，他就盯着那点疼，一秒一秒地熬。

脚步声经过他的门口，没有停。削平的门槛和满地柴灰，让“认领”落了空——那东西的目光扫过他的住处，像扫过一块空地。

天快亮时，潮退了。裴远瘫在墙角，浑身抽搐，眼白上的旋纹血丝多了两圈，可他还活着，还认得自己是谁。

镇子少了十几个人。活着的人第二天照常开门、晒网，绝口不提昨夜，仿佛那些空出来的屋子从来就没住过人。山路上的落石，天亮后不知被什么清开了——海送走了该送的，也就放客人走了。

裴远搭上第一班离镇的车。他没能救下那些人，他连试都没试——他很清楚，试了只会多添一个献者。他带走的，只有那本记满旋纹、吟诵与航路坐标的笔记，还有一张从档案室撕下的献祭图。

回到城里，他把这些交给了负责封存这类事件的机构。对方看完，沉默良久，只说了一句：“你能活着把这些带回来，已经比那支船队强。”

裴远没接话。他知道自己赢的不是那个深处的东西——没人赢得了它。他只是从它的名单上，把自己的名字，用一把小刀和一捧柴灰，划掉了。往后很多个夜里，他还会听见那段吟诵，在梦的边缘数着下一次涨潮。而他要做的，只是每一次都记得，自己是谁。
