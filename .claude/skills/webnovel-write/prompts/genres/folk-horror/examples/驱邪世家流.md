# 驱邪世家流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

来请顾云章的是个中年妇人，进门先在门槛外站了半天，才敢抬脚。

“顾师傅，我家闺女……夜里总说门外有人喊她。”妇人搓着衣角，“可门外一个人都没有。她一天比一天瘦，眼窝都陷下去了。跑了三家医院，查不出病。”

顾家做这一行，到顾云章是第四代。规矩他从小听到大：不主动揽事，不夸口保准，多大的本事接多大的活。他没急着应，先问了三样：闺女多大，几时起的病，家里近来有没有办过白事。

妇人一一答了。姑娘十九，病是半月前起的，家里上月刚给病故的老爷子办了丧。

顾云章心里有了数，却没说破。他随妇人去了她家，进门先看那姑娘。姑娘蜷在床上，见了生人也不躲，只是直勾勾盯着门口，嘴里无意识地应着：“来了……这就来了……”

他没看姑娘多久，反倒转身去看堂屋供着的老爷子遗像。看了一会儿，又问妇人：“老爷子走的时候，手里是不是攥着东西没松开？入殓的人是不是费了好大劲才掰开？”

妇人骇得后退一步：“你、你怎么知道？”

“不是我知道。”顾云章收回目光，“是他还没走利索。这事我能接，但有话说在前头——今晚之后，你家这门亲，怕是保不住了。你若舍得，我就动手。舍不得，我这就走。”

## 核心场面

顾云章要的东西不多：一碗净水，一段红线，还有老爷子入殓那天，从他手里掰出来的物件。

妇人翻箱倒柜找出来，是半枚旧铜锁。顾云章接过来一看就明白了。这不是招邪，是牵挂——老爷子放不下的，压根不是孙女，是这半枚锁对应的另一半。

“缠着你闺女的，是老爷子。”他把铜锁摆在净水碗边，“可他要找的不是她。你闺女八字轻，又是头七里最亲近他的人，他一时寻不着正主，就顺着最近的这条线喊。喊得久了，活人的魂就被他一点点带走了。”

妇人腿一软：“那、那正主是谁？”

“另一半锁在谁手里，正主就是谁。”顾云章取过红线，一头系在铜锁上，一头蘸了净水，缠上姑娘的手腕，“这道线不能用寻常法子，得用他生前的物件牵着他自己走。等会儿无论听见什么、看见什么，你都不许哭，不许喊你闺女的名字。你一喊，他就以为她答应了，这就再断不开。”

子时，堂屋的灯毫无缘由地暗下去。姑娘忽然坐直了，用一种苍老喑哑的声调开口：“……锁呢？我的锁……”

妇人捂住嘴，指甲掐进掌心，没出声。

顾云章把那半枚铜锁举到姑娘眼前，声音又稳又沉：“老爷子，锁在这儿。您要找的人不在这屋。您攥着它走了大半辈子，如今松了手，我送您去见她。这丫头，是您嫡亲的孙女，您忍心带她走？”

姑娘的身子晃了晃。喑哑的声音里，头一回有了迟疑。灯芯猛地爆了个火花，红线绷直，又缓缓松了下来。姑娘一头栽回枕上，昏睡过去，眉头舒展，是半个月来头一次睡得安稳。

## 收益兑现

天亮前，顾云章把那半枚铜锁用红布包了，让妇人明日送去城西的养老院——老爷子早年有个相好的，另一半锁，在那位老人手里。

“他不是恶祟，是执念。”临走时他跟妇人交代，“执念了了，他自己就走了。你闺女养几天就缓过来，往后无病无灾。只是那门亲事……”他顿了顿，“提亲那家，八字跟你闺女本就相冲，这半月又沾了这事的晦气。断了，是好事。”

妇人千恩万谢，要塞钱。顾云章只收了规矩内的数目，多的分文不取——这也是祖上传下的行规，趁人之危加价的钱，接了要折自己的福。

回到家，顾云章翻开那本传了四代的册子，在“牵魂”那一节的空白处，添了新的一行：物随人走，锁分两处，牵者需以本主之物导之，忌活人应声。这是他头一回独立解开“分锁牵魂”的局，祖父的手记里只记了症候，没记破法。如今这一页，是他自己填上的。

添完字，他对着堂屋里祖辈的牌位上了炷香。做这一行，道行不是喊出来的，是一桩桩案子啃出来的。今夜之前，他见过缠身的、错葬的，唯独没见过这样牵着旧物、认错了人的。

香灰落下的时候，他想起祖父生前的话：咱们这行送走的，多半不是恶人，是放不下的人。你手里的符也好，线也好，说到底不是拿来降妖的，是拿来劝人松手的。

天光透进窗棂。顾云章合上册子，等着下一个进门先在门槛外站半天的人。
