# 白事手艺流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

程一水入行第三年，头一回单独主持入殓。

主家在青河镇东头，逝者是位七十多岁的老太太，走得安详。程一水按师父教的规程来：净面要从额头往下巴抹，三下成，不许回手；寿衣穿单不穿双，扣子要用布带代替——扣子扣子，扣住儿孙，这一行忌讳这个。

一切都顺，直到给老太太合手的时候。

老人的右手攥着，攥得很紧。程一水轻轻去掰，掰不动。他没敢使蛮力——师父说过，逝者攥着的东西，一定是要紧的，硬掰是大不敬，得先问。他俯下身，凑近老人耳边，声音放得又轻又正：“老人家，我是替您装裹的。您手里的物件，是要带走，还是要留下？带走，我给您安顿好；留下，您就松松手。”

灵堂里静了几息。老人的手指，一根一根，缓缓松开了。

掌心里躺着一枚顶针，磨得发亮，边上还缠着半截褪色的红丝线。程一水把顶针托起来，回头问守灵的孝子：“这物件，家里谁认得？”

四十多岁的儿子凑过来看了一眼，摇头：“没见过。我妈做了一辈子裁缝，顶针有好几个，这个……不像家里的。”

程一水心里咯噔一下。老人临终攥着一枚家人不认得的顶针，攥得死紧,喊一声却又肯松手——这不是要带走的东西。

这是要还给谁的东西。

## 核心场面

守灵第二夜，长明灯灭了三回。

头一回，程一水当是风，添了油。第二回，他起身把灵堂门窗都掩严实了。第三回灯灭的时候，屋里一丝风都没有，灯芯却像被人两根手指掐熄的，连一缕烟都是直的。

按老规矩，长明灯无风自灭三次，是逝者有话没说完。程一水没慌。他把孝子请出去，独自跪坐在灵前，取出白天那枚顶针，摆在灯台边上，重新点灯。

“老人家，话我替您带。”他说，“可我得知道带给谁。您给个示意。”

灯苗静静烧着。烧了约莫一炷香，灯花忽然爆了一下，火苗朝着灵堂西边歪过去，歪了三次，次次朝西。

第二天,程一水去问镇上上了年纪的人。镇西早年有条裁缝街，四十年前失过一场火，烧死了一个学徒姑娘。老人们说，那姑娘生前跟东头的一个小裁缝要好，两人拿一对顶针当的信物。火灾之后，小裁缝嫁了别人，就是如今这位老太太。

程一水回到灵堂，把打听来的事对着灵位讲了一遍，末了说：“您攥了四十年,是想给她送回去。这事我接了。出殡那天，绕道裁缝街旧址，我替您把顶针埋在那儿。您看行不行？”

长明灯的火苗，安安稳稳，亮得比哪一晚都精神。当夜再没灭过。

## 收益兑现

出殡那天，抬棺的杠子头起初不乐意绕路：“东头到坟山明明直路，绕西边多出二里地!”

程一水只说了一句：“不绕，这棺你抬不动。”杠子头将信将疑。起棺时八个人喊着号子，棺身轻得反常，走到岔路口，众人下意识要走直路，棺身猛地一沉,八条汉子齐齐一个趔趄。掉头朝西，又轻了。杠子头脸都白了，此后一路无话。

到了裁缝街旧址，程一水按约把那枚顶针连着红丝线，埋在了老槐树下。埋下去那一刻，风过树梢，满树叶子沙沙响，像谁长长舒了口气。后头的白事，顺顺当当，落葬时天上出了日头。

事毕结账，孝子额外封了个厚红包。程一水按行规只抽出讲定的数目，其余原封退回：“白事的钱，讲好多少是多少。多拿一分，手艺就脏了。”

回到铺子，师父正在扎一匹纸马，头也不抬：“灯灭三回，你没喊我。”

“您教过，先问，后办，办不了再搬师父。”程一水把过程讲了一遍。师父听完，手里的活计停了停，从柜子底下摸出一个布包推过来。打开是一套入殓用的老铜钱，包浆温润，是师父自己用了三十年的家什。

“拿着。往后镇东这一片的活，你能自己接了。”师父重新低下头扎他的纸马，“记住，咱们这行，手艺是替死人办事，良心是替活人积德。那姑娘等了四十年，老太太揣了四十年——你送到了，两边都能睡个安稳觉。”

程一水捧着那串铜钱出门。日头正好，街上人来人往，谁也不知道昨天有一桩四十年的心事，落了地。
