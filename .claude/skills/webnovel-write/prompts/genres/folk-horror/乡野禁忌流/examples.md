# 乡野禁忌流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

回槐树屯的第一晚，姑姑就跟陈小满交代了三件事。

天黑以后不去村尾的老碾坊；晾在院里的衣裳，日头一落必须收进屋；后山那条岔往乱葬岗的小路，白天也别走。姑姑说这些话的时候手里择着豆角，语气平常得像在说明天赶集，可择豆角的手一直没停，也一直没快。

陈小满是回来给爷爷迁坟的。他在城里长大，对这些老讲究向来是听一半丢一半。当晚他洗了件衬衫，随手搭在院里的铁丝上，就睡下了。

后半夜他被院里的动静弄醒。不是风声，是布料被抻开又松掉的声音，一下，一下，很有耐心。他趴到窗缝上看，月光底下，那件白衬衫直挺挺地鼓着，两只袖子平平抬起，像是有人正把胳膊往里伸。

院里没有风。晾衣绳旁边的狗尾巴草，一根都没动。

第二天一早，姑姑看见铁丝上的衬衫，脸色当时就变了。她没骂人，只是把衬衫用火钳子夹下来，连盆一起端到院外烧了，回来时才说了一句：“跟你说过日落收衣裳。衣裳过了夜，就不知道让谁套过了。”

陈小满想说昨晚看见的事，话到嘴边又咽了回去。姑姑烧衣裳的时候，他注意到她朝村尾老碾坊的方向看了一眼，很快，但确实看了。

## 核心场面

迁坟定在初八，可初六夜里，屯子里就不对了。

先是各家的狗。天一擦黑，全屯的狗冲着村尾一齐叫，叫到半夜，忽然又一齐哑了，像被同一只手捂住了嘴。接着是六叔公家出的事——他家小孙子夜里说梦话，一口老腔老调，说的是“碾子还差三圈，麦还了才能走”。六叔公听完当场就白了脸。屯里人都知道，那是死了快四十年的看碾人石老蔫的口头禅。

初七清早，姑姑领着陈小满去找屯里辈分最高的三奶奶。三奶奶耳背眼花，听完却只问了一句：“动土的日子，是不是选在初八？”

姑姑点头。三奶奶把旱烟在鞋底磕了磕：“坏了。初八是石老蔫的忌日。你们要迁的坟，紧挨着他当年埋的那块地。他这是听见动静，当有人来还麦子了。”

原来饥年的时候，屯里各家从碾坊借过麦，石老蔫记着账。人死那年冬天，账没清，坟草草埋了，碾坊一封就是四十年。这些年屯里日子好过了，没人再提那笔账。

“他不害人，他是等。”三奶奶说，“可等的年头太长，等成了执念，就由不得他了。今晚要是再没人搭理，明天动土，你们爷俩一个都别想囫囵着回来。”

姑姑的手在发抖。陈小满听见自己开口：“三奶奶，那笔账，还能还吗？”

三奶奶抬起浑浊的眼睛，头一回正眼看他：“账在人心里，就还得上。夜里去碾坊的人，得是他家的后人——你姑姑当年，是石老蔫收过的干闺女。”

## 收益兑现

那晚的事，屯里后来传了很多年，说法一年比一年玄。只有陈小满知道原样。

他和姑姑提着两斗新麦、一刀纸，天黑透了才推开碾坊的门。碾盘上积了四十年的灰，中间却干干净净一圈，像总有人在推。姑姑把麦倒进碾眼，跪下去磕了三个头，一笔一笔地念账：谁家借了几升，如今折成新麦几斗，一样样码在碾盘边上。

念到最后一笔，碾坊里起了风。碾盘吱呀呀自己转起来，不急不缓，正好三圈。三圈转完，风停了，满坊的灰尘簌簌落定，像一口憋了四十年的气，终于吐了出去。

初八迁坟，顺顺当当。傍晚全屯的狗又叫了一场，这回叫得欢实，冲着后山的方向，摇着尾巴。

临走那天，三奶奶把陈小满叫到跟前，塞给他一枚磨得发亮的老铜钱：“那晚你在碾坊门口站着没跑，腿肚子抖成那样也没跑。这就是根器。老理儿这东西，城里用不上，可你既然看得见听得着，就得学着懂——不为拿它吃饭，为的是往后遇上了，知道该给哪边磕头，该替哪边还账。”

陈小满捏着那枚铜钱上了车。车过村尾，老碾坊的门开着，日头照进去，亮堂堂的。他忽然想，石老蔫守了一辈子碾坊，末了等的不过是有人来把账念一遍。

死人要的东西，从来都不多。多的是活人欠着不还。
