# 朝堂权谋流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

散朝的钟声还没歇，裴慎已经知道今日这道弹章不是冲着别人来的。

他是户部一个不起眼的员外郎，管着漕运账目。方才御史台的一名新进言官出班，参劾漕运沿线三年亏空四十万石，措辞凌厉，直指经手其事的户部官员“中饱”。满殿的目光有意无意地扫过他。

回到值房，副手小吏关上门，压着嗓子急道：“大人，那御史姓名底细我打听清了，是次辅门下的族侄。上月次辅在府中设宴,请的都是漕运沿线的关卡主官——这一本，分明是次辅要拿漕运开刀，先剪您这只手,好把漕运这块肥肉整个吞下去!”

裴慎不慌不忙地把桌上的账册合拢：“他弹的是三年亏空。这三年，前两年经手的是谁？”

小吏一怔：“是……已致仕的老侍郎。您接手，才不到一年。”

“那就对了。”裴慎端起茶,吹了吹浮沫,“次辅急着扳倒我,反倒替我把话头递到了眼前。你去做两件事:一,把这三年漕运的原始底档,连同各关卡的验收回执,原封不动封好,亲自送去都察院存档;二,替我递个牌子,我要请旨——请朝廷彻查漕运,查个水落石出。”

小吏骇然：“大人!人家参您,您反倒请查自己?这……”

“他要查一年，我请查三年。”裴慎搁下茶盏，眼里没什么波澜，“查得越深，越是我的好处。你只管去办，三日之内，满朝就该知道，是谁在心虚。”

## 核心场面

廷议彻查漕运那日，殿上气氛紧绷得像拉满的弓。

次辅一党本以为稳操胜券。那名御史再度出班，历数亏空数目，末了拱手：“漕运积弊，非严查经手之员不能肃清。臣请拿裴慎下问。”

裴慎出列，不辩一字，只俯身呈上一函：“臣请陛下先阅此档。这是三年漕运的原始底账与各关验收回执，臣接手时便原样封存，一字未动，现存都察院。臣斗胆请问王御史——这四十万石亏空，是哪一年、哪一段、经谁的手核销的？”

御史一滞。他手里那本亏空账，是次辅府上做出来递给他的，压根经不起对原始底档。

裴慎不等他答，转向御座，声音清朗：“臣查过了。前两年漕粮损耗，皆有老侍郎在任时的批文核销，账目相符，并无亏空。真正对不上的，是各关卡收受‘漕规’的私账——臣这里，另有一本。”

他呈上第二函。殿中霎时死寂。那本私账上，记着沿漕数处关卡三年来私收的规银流水，而收银者，多是次辅门生故吏。

次辅的脸色一寸寸沉下去。他到此刻才明白，裴慎请旨彻查，查的从来不是自己，是他布在漕运上的这条财路。皇帝翻着那本私账，久久不语,末了只淡淡道:“王御史所参亏空,查无实据。这本私账上的人，交三法司。”

## 收益兑现

三日后，那名御史下了诏狱，牵连罢黜的关卡官员共七人，皆是次辅一系。次辅在朝堂上折了一条臂膀，数月不敢再向漕运伸手。

真正的分量，在散朝后才落下来。內侍传旨，召裴慎入宫奏对。

御前，皇帝把那本私账搁在御案上，问得随意：“漕运积弊，你既查得清，可有整治之法？”

裴慎早有腹稿，从关卡验收、账目对销到漕规归公，一条条奏来，条理分明。皇帝听罢，颔首良久，说了一句：“漕运总督之下，设一漕务清查使，专司此事。你去做。”

这是实缺，是能直接调动沿漕关卡、稽核百万漕粮的实权。裴慎叩首谢恩，退出殿门时，宫墙外的日头正好。

值房里，小吏迎上来，声音都在发颤：“大人，外头都传遍了!方才连吏部的张郎中都特意过来,改口称您……称您‘裴使君’了。”

裴慎解下官服上的尘,慢慢坐下。一个不入流的账房员外郎,一场廷议之后,成了握着漕运稽核之权的清查使。次辅那本用来害他的假账,反倒成了他登阶的垫脚石。

“别急着高兴。”他提笔蘸墨,在新的公文上落下第一个字,“次辅断了一臂,不会善罢甘休。漕规归公动的是多少人的钱袋,这趟差,才刚开头。你去替我办三件事:把沿漕各关的主官名录理一份来,注明谁是次辅的人、谁是骑墙的;查一查漕运总督近来与哪些盐商往来;再备一份清丈漕田的条陈——我要的,不只是查一回账,是把这条河的规矩,从头改一遍。”

小吏应声要走,又被他叫住。“记住,”裴慎搁下笔,“从今日起,我升的越快,盯着我的眼睛越多。回府的路,换着走;府里的账,你亲自管。”
