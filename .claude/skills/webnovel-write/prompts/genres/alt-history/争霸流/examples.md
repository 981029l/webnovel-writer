# 争霸流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

齐云关的城头挂着三面残旗，是昨夜溃兵留下的。

萧决勒住马，看着关下涌来的流民，估摸着有四五千口。老的拄着棍，小的背在筐里，一路从战乱的河东腹地逃过来，见了关上的旗就跪。他麾下这支人马满打满算不过八百，还有一半是新募的乡勇，握刀的手都在抖。副将周堪凑过来低声道：“将军，收不下这么多张嘴。城里粮仓昨日就见了底，自家弟兄再撑五日都难。”

“粮不在城里。”萧决抬手一指东南，“昨夜溃退的官军，把三百车军粮丢在了黑石渡。守渡的是溃兵头子雷豹，四百人，无主之师。”

周堪一愣：“将军是想……”

“流民要吃饭，雷豹要出路。”萧决翻身下马，把缰绳丢给亲兵，“你带两百人打出我的旗号，去渡口跟雷豹谈。就说齐云关缺一个粮草官，他若肯来，三百车粮我认，四百弟兄我养。”

周堪迟疑：“万一他反咬一口？”

“他反不了。”萧决望着关下黑压压的人头，声音很稳，“这些流民,今日跟着谁有饭吃,明日就替谁扛刀。他若敢动手,我不用出兵,单是这四五千张嘴,就能把他的粮车分光。他是聪明人,看得懂这笔账。”

三日后，黑石渡的三百车军粮进了齐云关，雷豹带着四百人归了萧决麾下。流民按户编册,青壮五百入营,余者以工代赈修补城防。齐云关的粮仓，重新有了底;萧决手里的兵，头一回过了两千之数。

## 核心场面

真正的仗，在半月后打响。

据斥候回报，邻境的岳州刺史孙鄴发兵一万五千，要趁萧决立足未稳先下齐云关。萧决把周堪、雷豹并几个新附的头领召到堂上，摊开一张手绘的舆图。

“孙鄴兵多，我不过两千,硬碰是死路。”他指尖点在一处,“但他一万五千人马,每日耗粮八十石。这些粮,走的是清河水道。清河窄处只容两船并行,两岸芦苇高过人头。”

雷豹眼睛一亮：“将军要烧他的粮船？”

“烧粮是其一。”萧决又点向关前一片洼地,“孙鄴急于速胜，必从正面强攻。我在关前掘暗壕、埋鹿角,示弱诱他猛攻。他攻得越急,阵型越散。等清河火起,他后无粮草,前有坚壁,军心自乱。”

十日后,事如所料。孙鄴大军三攻齐云关不下,士卒疲敝。第四夜,清河火光冲天,四十条粮船尽付一炬。次日清晨,岳州军大营先自乱了——有人喊断粮,有人喊萧决的伏兵抄了后路,谣言比刀子还快。

萧决亲率八百精骑自侧翼杀出,雷豹的降兵在前引路,专拣旗鼓所在处冲。降兵熟悉岳州军的号令,一路高喊“孙鄴已走”“清河粮尽”,直插孙鄴中军。军心本已浮动,这几嗓子喊下去,阵脚彻底崩了。这一战,岳州军溃退六十里,自相践踏死伤无数,降者四千,孙鄴仅率残部逃回岳州。齐云关外,再没人敢小觑那面写着“萧”字的黑旗。

## 收益兑现

清点战果那日，堂上气氛前所未有地热。

周堪捧着册子念：“此战俘敌四千，收编三千二百;缴获甲胄一千三百副,战马六百匹,粮草够全军支用两月。岳州所辖的临水、上邽两县,守将闻风献城归附。”

萧决没急着高兴。他把降将里一个叫韩略的书生模样的人叫上前——此人本是孙鄴帐下参军,昨夜劝孙鄴退兵不成,才被萧决的斥候在乱军里“请”了来。

“韩先生昨夜说，孙鄴之败，败在贪功冒进。”萧决亲手替他斟了一碗酒，“如今我据三县之地，将卒一万有余，正缺一个替我算清粮草兵员的人。先生可愿留下？”

韩略盯着他看了半晌,忽然离席一拜:“将军能于关下先算粮草、后算人心,略愿效犬马。”

一个月前,萧决还是个守着八百残兵的关隘小校。如今,齐云关连着临水、上邽,舆图上属于他的地界,头一回连成了一片。周堪在旁笑道:“将军,该给弟兄们请功,也该给咱们这支人马……起个正经名号了。”

萧决望向堂外新竖起的黑旗,旗角在风里绷得笔直。麾下诸将的目光都落在他身上,等他一句话。他缓缓道:“名号不急。先把临水、上邽两县的降卒整编了,老弱屯田,精壮入营;把韩先生要的账册和户籍理出来,该征的税征,该免的赋免——地盘不消化,打下来也是替人守的。”

他顿了顿,手指在舆图上从齐云关一路划到岳州:“等三县兵满两万,粮支半年,再取岳州。取了岳州,这名号,孙鄴替我们传遍河东。”
