# 情感反杀 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

我哥结婚，没请我。

我是从朋友圈刷到的。九宫格的婚纱照，底下一堆人道喜，我翻到最后也没找到我的位置——不光婚礼没请，连这条动态都把我屏蔽了，还是别人转给我我才看见的。

从小到大就是这样。他成绩好，我成绩差；他是别人家的孩子，我是那个"你看看你哥"。爸妈的偏心明晃晃摆在脸上，他也从来没为我说过一句话。上大学那年家里钱紧，只够供一个，我妈想都没想就让我去打工，供他读研。

我不怪爸妈，我怪他。他明明可以拦一句的。他没有。

结婚这么大的事把我排除在外，我算是彻底看清了。这个哥，从我记事起，就没把我当过家人。我给他发了条消息："恭喜，不用还我学费了。"发完就把他删了。

我以为这辈子跟他就这么散了。直到半个月后，我妈住院，我在缴费单上看见了一个数字。

## 核心场面

缴费单上写着，住院押金已由家属代缴，五万。

我妈的病来得急，我手里根本凑不出这个数。我第一反应是我哥垫的——可我不想欠他。我去问护士站，谁交的钱。护士翻了记录，念出一个名字，不是我哥。

是一个我完全陌生的名字。

我拿着那个名字去问我妈。我妈躺在病床上，虚弱地摆手，不肯说。我追问了三遍，她才别过脸，眼角淌下泪来："是你哥……用的假名。"

我愣在原地。

我妈断断续续地讲。我哥研究生毕业后，工作头两年攒的钱，一分没动过，全存着。他知道我恨他，知道我不会要他一分钱，所以这些年，家里凡是要用钱的地方——我妈的降压药，老家漏雨的屋顶，还有这次的住院押金——他都用别人的名字悄悄垫上，从不让我知道。

"那你的学费呢，"我妈哭着说，"当年供他读研的钱，他工作第一年就一笔一笔还给我了，让我别告诉你。他说……他说你要是知道是他的钱在撑着这个家，你会更难受。"

我手里的缴费单，抖得几乎拿不住。

## 收益兑现

我翻出跟他最后那条聊天记录。"恭喜，不用还我学费了。"

原来那句话，字字都戳在他心上。他没有辩解，因为他知道怎么解释都是错——他要么承认自己一直在偷偷补贴，让我觉得欠他人情；要么什么都不说，继续当那个"从没为我说过话"的哥。他选了后者。他宁可让我恨他一辈子，也不想让我背上一分愧疚。

婚礼不请我，也是同样的道理。我妈后来才告诉我，他原本发了请柬，是我爸拦下的——我爸怕婚礼上亲戚又当众拿我和他比，让我下不来台。我哥知道后，索性把那条朋友圈也对我屏蔽了。他不是把我排除在外，他是怕我难堪，一个人默默替我挡掉了所有可能刺痛我的场合。

我跑到他公司楼下，等到他下班。他看见我，脚步顿住，像是不知道该说什么。

我把这些年的事一件件砸给他，最后问他：你图什么？

他站在那儿，很久，才轻轻说了一句："你是我弟。"

三个字，我在原地站了很久，眼泪一下子下来了。从小到大我以为最不拿我当家人的那个人，是唯一一个，从没把我从"家人"里划出去过的人。

后来我妈出院，我们哥俩把她接回老家。饭桌上我给他夹了块排骨，学着我妈的口气说："你看看你弟。"他一愣，然后笑了。那是我这辈子，第一次主动叫他哥。
