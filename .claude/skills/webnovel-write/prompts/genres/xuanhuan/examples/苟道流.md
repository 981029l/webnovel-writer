# 苟道流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

丹房杂役季长明给周执事斟茶的时候，手很稳，头压得很低。

"药园西圃的活，这个月还是你盯着。"周执事呷了口茶，"手脚干净点。"

"是。"季长明退出去，脸上还是那副木讷相。心里却把刚才的三句话拆开来过了一遍——周执事说"还是你盯着"，说明本来有人要顶他的位置，被压下去了；能压这事的只有丹房赵长老，而赵长老上旬刚收了他孝敬的两株百年地黄。四十灵石的孝敬，换来继续守着西圃，值。

西圃是宗门里最没人稀罕的差事，出产的都是低阶灵草。但没人知道，西圃东北角那口废井底下，井壁的青苔一年比一年厚——底下有灵脉的分支。季长明守了两年，每晚借着井里的灵气修炼，明面上还是炼气五层，实际早已摸到炼气九层的门槛。这两年他连吐纳的动静都收着，功法专挑最不显山露水的《敛息诀》修，见了谁都先低头。宗门上下提起他，评语出奇一致：老实，没出息。

他要的就是这八个字。

他回到西圃，照旧锄草、施肥、记档。路过废井时脚步没有半分停顿。

再苟半年。半年后宗门大比，内门放开三个名额——那才是值得他出手的时候。

## 核心场面

麻烦比大比先来了。内门弟子孟浩带着两个跟班堵在西圃门口，说要"借"井边那块地建炼器坊。

"季师弟不会不给这个面子吧？"孟浩笑着，手里把玩一枚火纹符。

季长明躬身，心里已经把这件事前后捋了一遍。孟浩上个月输了坊市的赌斗，欠了一屁股灵石，急着建炼器坊回本；他挑西圃下手，是笃定一个杂役不敢声张。急，又没退路——这样的人最好拿捏。他把头压得更低："师兄要用地，我一个杂役哪敢拦。只是西圃归丹房管，我做不了主，师兄找周执事批个条子，我立刻腾。"

孟浩眯起眼。他当然批不下条子——丹房和他师父执法堂正为矿洞的事顶着牛，这一点，季长明三天前就从两个执事的闲谈里听明白了。孟浩绕开条子直接来压人，恰恰说明他等不了，也说明他背后没人真撑腰。

"敬酒不吃。"孟浩掌心火光一涨。

季长明后退半步，声音发颤："师兄动手前，最好知道两件事。第一，西圃每月初一丹房要来盘点，今天是二十九。第二——"他抬起头，眼里那点木讷褪得干干净净，"三天前你私采药园朱果的事，赵长老的案头明早就会有一份记档。是我压着没递，还是现在就递，师兄选一个。"

孟浩的火光僵在掌心。他盯着季长明看了足足五息，忽然觉得这个杂役从头到尾没怕过。

"你早就在等我上门。"

"不敢。"季长明重新低下头，"师兄慢走。"

## 收益兑现

三天后，孟浩托人送来一只木匣：一枚聚元丹，二十块灵石，外加一句"前事一笔勾销"。

季长明收了。聚元丹市价一百二十灵石，正是他冲击炼气九层缺的最后一味外助——这一点孟浩不知道，送礼的人只当是封口的行价。他当晚在废井底坐到天亮，丹力混着灵脉的地气在经脉里走满九个周天，气海一震，炼气九层，成了。真元收束入体的那一刻，他睁眼看了看井口那方灰白的天，又把气息压回炼气五层的水位——涨了修为，藏得更深。

账面上的收益不止这些。孟浩背后的执法堂欠了他一个人情，丹房这边，周执事只当西圃太平无事，对他愈发放手。两头都不知道，那份朱果的记档他抄了两份，一份压在井底，一份混进了丹房的旧档——什么时候用，用来换什么，主动权在他手里。

明面上，他还是那个炼气五层的杂役，锄草、施肥、记档。周执事照旧每旬来收一次孝敬，照旧夸他一句"稳当"。没人多看他一眼，这正是他花了两年经营出来的位置。

大比还有五个月。三个内门名额，盯着的人里有炼气八层的、九层的，还有孟浩这样的关系户。季长明把名单在心里排了一遍，一个个记下修为、功法路数、背后的靠山。

够了。到时候他只需要赢三场，而对手到现在还不知道有他这个人。
