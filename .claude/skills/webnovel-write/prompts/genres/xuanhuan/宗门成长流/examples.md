# 宗门成长流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

内门大比的报名榜贴出来那天，外门弟子云疏挤到最前排，只为看清一行小字：外门前十，可越级参加内门大比，胜三场者，收入内门。

他现在排外门三十七。

云疏没急着挤回去，先把榜上前十的名字记下来。第九名到第七名都是老面孔，卡在这个位置一两年了，说明有瓶颈；第五名钱敬修上个月刚突破炼气七层，正是气势最盛的时候，动不得。真正的空档在第八名——那人下月要闭关冲筑基，大比多半弃赛。

"想进前十？"同院的师弟撇嘴，"你炼气六层，往上全是七层八层，做梦。"

云疏笑了笑没接话。做梦的人抢的是名次，他抢的是规则里的缝。

外门升迁不只靠打，还靠贡献点。演武台赢一场加三点，任务殿交任务加点，藏经阁抄录典籍也加点——积够五百贡献点，可直接向执事堂申请一次"越阶挑战",挑赢当前排名比自己高五位的人,名次互换。

他翻出自己的贡献牌:四百七十一点。

差二十九点。任务殿今天新挂的除虫任务,正好三十点。云疏把名字报了上去,顺手在心里排好了后面一个月的日程:先用贡献点换一次越阶挑战,再靠越阶挑战一路把名次咬上去。规则是宗门定的,可规则里的每一道缝,都够一个肯算的人往上爬。

## 核心场面

越阶挑战定在演武台第三场,云疏点名挑第三十二名的孙河。

孙河炼气七层,比他高一层,台下都当他自不量力。孙河自己也这么想,上台就催:"认输还来得及。"这半年云疏在演武台看了他四场,清清楚楚:孙河真元厚,但剑法只会大开大合,一旦被贴身就没了章法。挑他,是算过的。

云疏没答话,拔剑。他这半年在藏经阁抄录换来的不只是贡献点——那门《流云十三剑》的残篇,别人当废纸,他补全了前七式。剑走轻灵,专克孙河这种一味堆砌真元的莽夫。

孙河真元外放,剑气如墙压来。云疏不硬接,脚下踏着演武台的刻纹错步,第三式"云开"卸掉七成剑气,顺势贴身。孙河慌忙回防,却发现对方的剑尖已经点在自己手腕的脉门上——再进一寸,握剑的手就废了。

"承让。"云疏收剑。

台下静了一瞬。裁判执事扬声:"云疏胜。名次互换,云疏升外门三十二名。"记名弟子在名册上把两个名字对调,笔尖顿了顿——这规矩立了十几年,用越阶挑战一路往上打的,他还是头一回记。

孙河站在原地,握剑的手还在抖。他到这时才明白,对面这个炼气六层从上台起就没打算跟他拼真元——人家算的是名次,不是意气。

云疏下台,径直走向贡献牌兑换处。赢下这场,又是三点入账,还剩四位要挑。

## 收益兑现

一个月,四场越阶挑战,云疏从三十二名爬到外门第九。

执事堂的长老亲自把新的身份牌递给他:一枚泛着淡青光的外门精英令。"前十弟子,每月多领三十灵石月俸,藏经阁开放到二层,演武台可预约长老指点一次。除此之外,"长老多看了他一眼,"你这一个月连升二十三名,执事堂记了你一功。"

云疏捏着令牌,指节微微发力。三十灵石月俸是从前的三倍;藏经阁二层,《流云十三剑》后六式的全本就在那里;而那次长老指点,足够他把炼气七层的门槛看透。

三天后就是内门大比。他要的从来不是外门第九,是那三场胜、那扇内门的门。

那个下月闭关的第八名果然弃了赛,空出的位置,现在是他的起跑线。

离开执事堂,云疏又去了一趟报名榜。这回他不用挤——前排的人见了那枚青光令牌,自动让出一条道。半年前那个撇嘴说他做梦的师弟也在,张了张嘴,到底没敢出声。

云疏在内门大比的名册上,写下自己的名字。笔锋落定,他抬头望向宗门后山那座内门弟子才能进的问剑峰。

下一层的门槛,已经在脚边了。
