# 凡人流 风格范文

以下片段为文风示范，人物、地名均为演示虚构，禁止照抄进正文。

## 开篇

任务殿的公告牌前排了二十来人，陆青川站在最外圈，先看的不是赏格，是落款日期。

南岭采药，报酬四十灵石，挂了半个月没人接。他心里过了一遍：半个月前，南岭失踪了两个炼气弟子，任务殿把赏格从二十提到四十，还是没人碰。危险是真的，但四十灵石也是真的——够他买两瓶引气散，把卡了三个月的炼气四层顶过去。

"陆师弟也看南岭的任务？"旁边有人搭话，是外门的胡姓弟子，笑得热络，"要不咱俩搭伙，报酬对半？"

陆青川摇头："我修为低，不敢去。"

他转身走了。胡师兄炼气六层，什么任务接不得，偏偏来拉他一个炼气三层搭伙？多半是要人探路挡灾。南岭他要去，但得自己去，而且不走正道——三年前他在坊市淘到过半张南岭旧图，图上标着一条采药人废弃的西侧小径。

回到洞府，陆青川把旧图铺开，就着油灯又核了一遍。西径入口在乱石滩后面，绕远七里，但避开了失踪案发生的主谷。他从床底摸出攒了半年的家当清点：灵石三十一块，避瘴丹一瓶，下品符箓两张。避瘴丹带上，符箓留下——四十灵石的任务，犯不上把一百二十灵石的符箓押进去。

四十灵石的买卖，值得他花两天把路线和退路都算清楚再动身。

## 核心场面

崖壁下那丛紫脉参有七株，陆青川只掐了四株。

不是不贪，是算过账：紫脉参三年一熟，留三株，明年这里还是他的私库；全掐了，这条财路就断了。他把参用湿苔裹好收进背篓，刚要起身，西面林子里传来脚步声——两个人，走得急，不避枝叶。

他没跑，先退进崖壁的阴影里蹲下。跑是最蠢的选择，动静大，还暴露背篓里的货。他顺手抓了把碎土撒在翻动过的泥面上，又把两块山石挪回原位——做不到天衣无缝，但足够让来人晚发现一炷香。这一炷香，够他脱身了。

来的果然是胡师兄，身后跟着个生面孔，两人在参丛前停住。"奇怪，图上明明记的是七株……"胡师兄蹲下扒拉泥土，脸色沉下来，"土是新翻的，有人抢先了，走了不到半个时辰。"

生面孔骂了一句，要追。胡师兄却抬手拦住，往崖顶望了一眼："别追。能摸到这儿还知道留三株养地的，不是生手。为四株参跟人拼命，不划算。"

两人调头走了。陆青川在阴影里又蹲了一炷香，才从西侧小径下山。

回程他换了坊市东门进城——胡师兄的舅舅在南门当税吏，这事他半年前就打听清楚了。背篓上盖着一层普通草药，紫脉参压在最底下。城门口的巡卫扫了一眼就放行了，谁会为几把止血草翻一个炼气三层的背篓。

## 收益兑现

四株紫脉参，药堂给的收购价是每株二十二灵石。

陆青川没在药堂卖。他拿了一株去找回春堂的柳掌柜——柳掌柜的独子下个月冲击筑基，配药正缺紫脉参，这消息是他上旬帮柳家搬药材时听来的。急买家不问市价，这是坊市里颠扑不破的道理。

"三十五灵石一株，四株都要了。"柳掌柜捏着参须，头都没抬，"品相不错，采参的手法也干净，没伤须。小陆，这不是你第一回采参吧？"

"跟山里的老采药人学过几天。"陆青川答得滴水不漏。西径的事，多一个人知道就少一分价值。

一百四十灵石入袋，刨去这趟耗掉的一瓶避瘴丹和两天工夫，净赚一百三十二。陆青川在心里把账翻新：引气散两瓶四十灵石，突破炼气四层稳了；剩下九十二块，离筑基丹三千灵石的目标还差两千七百，但按这个月的进项，比原计划提前了四个月。

柳掌柜送他出门时多说了一句："小陆，下月秘境开启，堂里要收一批凝血草，价钱好说。"

陆青川应下了。凝血草他知道哪里有——南岭西径的溪谷里长了一片，那半张旧图上标着。

回洞府的路上他盘算着，明年开春，紫脉参又该熟了。这条路，才刚走出个头。
